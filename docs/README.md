# 시작

ui-lab은 프로젝트에서 만든 UI를 세 층으로 쌓는다.

| 층 | 위치 | 내용 |
|---|---|---|
| 컴포넌트 | `registry/components/` | 단위 컴포넌트. 데이터·브랜드 없이 props로만 동작 |
| 적용 사례 | `registry/blocks/` | 실제 프로젝트에서 컴포넌트를 조합한 화면. 출처 프로젝트를 `meta.source`에 남김 |
| 문서 | `docs/` | 작성 규칙, 패턴, 결정 기록, 학습 노트 |

## 가져다 쓰기
1. 갤러리에서 항목을 열고 코드를 복사하거나 `registry/<층>/<이름>/` 폴더를 통째로 복사한다.
2. 프로젝트 CSS에 `registry/tokens.css`의 `@theme` 값을 넣거나, 같은 이름의 색 토큰을 프로젝트 값으로 바꾼다.
3. Tailwind 4가 있으면 추가 설정 없이 동작한다. Vite·Next 모두 같은 코드로 쓴다.
