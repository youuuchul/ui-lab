# QA·출시 체크리스트
출시 전에 확인할 것과 출시 후 지켜볼 것.

## QA 체크리스트
- [ ] 인수 조건 전부 통과
- [ ] 빈 값·실패·권한 없음·느린 네트워크 처리
- [ ] 연속 입력(두 번 클릭, 빠른 전환)
- [ ] 모바일·데스크톱, 주요 브라우저
- [ ] 키보드만으로 사용, 화면 낭독기 라벨
- [ ] 한글 입력(IME 조합 중 Enter)
- [ ] 이벤트 로그가 정의대로 쌓임

## 출시 체크리스트
- [ ] 단계 출시 비율과 기간
- [ ] 모니터링 지표와 대시보드 링크
- [ ] 롤백 조건과 방법
- [ ] CS·운영 공지 (문의 대응 문구)
- [ ] 릴리즈 노트

## 출시 후
- 첫 24시간: 오류율, 가드레일 지표
- 1~2주: 핵심 지표, 실험 판단 기준
