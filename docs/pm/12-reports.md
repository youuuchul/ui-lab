# 보고서 템플릿
릴리즈 노트, 주간 보고, 회고, 실험 결과 보고.

## 릴리즈 노트
```markdown
## <버전 또는 날짜>
### 새로 생긴 것
- 사용자에게 보이는 변화 한 줄씩
### 바뀐 것
### 고친 것
```
사용자용은 변화가 주는 이점으로, 내부용은 변경 범위와 영향으로 쓴다. 이 저장소의 [업데이트 내역](#/docs/changelog)이 예다.

## 주간 보고
```markdown
## <주차>
### 지표
| 지표 | 지난주 | 이번주 | 변화 |
### 한 일
- 결과 중심. "~회의함"이 아니라 "~를 결정함"
### 다음 주
### 막힌 것 · 도움이 필요한 것
```
보고는 결론을 먼저 쓴다. 숫자가 바뀐 이유를 한 줄로 붙인다.

## 회고 (KPT)
```markdown
## Keep — 계속할 것
## Problem — 문제였던 것 (사실 중심)
## Try — 다음에 바꿀 것 (담당·기한)
```

## 실험 결과 보고
```markdown
# <실험 이름> 결과
결론: 채택 / 기각 / 보류 (한 줄)
## 수치
| 지표 | 대조군 | 실험군 | 차이 | 신뢰구간 |
## 해석
## 다음 행동
```
결론을 첫 줄에 둔다. 읽는 사람이 끝까지 읽지 않아도 판단할 수 있게.
