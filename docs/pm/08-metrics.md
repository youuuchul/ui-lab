# 지표 정의서
같은 이름의 지표를 모두가 같은 식으로 계산하게 한다.

## 칸
| 칸     | 내용                        |
|--------|-----------------------------|
| 이름   | 화면·보고서에 쓰는 이름     |
| 정의   | 한 문장                     |
| 계산식 | 분자 / 분모, 기간, 단위     |
| 이벤트 | 사용하는 로그와 조건        |
| 제외   | 테스트 계정, 내부 사용자 등 |
| 담당   | 정의를 바꿀 수 있는 사람    |

## 지표의 층
- 북극성 지표: 제품이 주는 가치를 대표하는 하나 (예: 주간 활성 대화 수)
- 입력 지표: 북극성을 움직이는 행동 (예: 첫 메시지 전송률)
- 가드레일: 개선 중에 나빠지면 안 되는 것 (예: 신고율, 이탈률)

## 예시
```markdown
이름: 첫 메시지 전송률
정의: 대화 화면에 들어온 사용자 중 첫 메시지를 보낸 비율
계산식: 첫 메시지 전송 사용자 수 / 대화 화면 진입 사용자 수 (일 단위, 사용자 기준 중복 제거)
이벤트: chat_view, message_sent(order = 1)
제외: 내부 계정
관련 기능: 추천 답변
```
추천 답변([채팅 입력창](#/components/chat-input))이 겨냥하는 지표가 이것이다.

## 퍼널
AARRR(획득·활성·유지·추천·수익)으로 단계를 나누면 어느 단계의 문제인지 먼저 좁힐 수 있다.
