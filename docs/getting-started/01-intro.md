# 소개
프로젝트에서 만든 UI를 적용 사례, 컴포넌트, 문서 세 층으로 모은 저장소.

## 구성
### [적용 사례](#/blocks)
- 실제 서비스 화면을 데이터·API 없이 다시 짠 조합
- 예: 캐릭터 대화 화면, 3D 역량 그래프

### [컴포넌트](#/components)
- 적용 사례를 이루는 단위 부품
- 기본 UI와 도메인 컴포넌트를 같은 분류 안에 둔다
- 예: 토글, 채팅 입력창, 원형 카운트다운

### 문서
- 시작하기: 설치 방법, 작성 규칙, UI 검수 기준
- 요소: 색상, 타이포그래피, 간격, 모션, 글쓰기
- 기획: PRD, 기능 명세서, 백로그, 실험 설계, 보고서 같은 PM 문서의 템플릿과 예시

### 항목별 기획 문서
- 적용 사례와 컴포넌트 상세에서 **개발 / 기획** 보기를 바꿀 수 있다.
- 기획 보기에는 그 항목의 기능 명세(상태, 동작, 예외, 인수 조건)가 있고, 적용 사례는 PRD 요약을 함께 둔다.

적용 사례 상세에는 쓰인 컴포넌트가, 컴포넌트 상세에는 그 컴포넌트를 쓴 적용 사례가 연결된다.

| 프로젝트                                           | 성격                              | 옮겨 온 것                                   |
|----------------------------------------------------|-----------------------------------|----------------------------------------------|
| [HeartTable AI](https://heart-table-ai.vercel.app) | 캐릭터와 대화하는 연애 시뮬레이션 | 대화 화면, 말풍선, 입력창, 타이머, 표정 전환 |
| [PetGlobe](https://petglobe.app)                   | 반려동물 돌봄 기록 서비스         | 은하수 글로브                                |
| Murder Mystery Generator                           | 머더 미스터리 시나리오 생성·진행  | 캐릭터·단서 화면                             |
| 웹 포트폴리오                                      | 링크형 포트폴리오                 | 3D 그래프, 원형 캐러셀, 텍스트 전환, 폰 목업 |

비공개 프로젝트의 코드는 브랜드 문구·실데이터·API 연결·프롬프트를 빼고 옮겼다. 이미지는 각 프로젝트에서 직접 만든 에셋만 쓴다.

## 기술 기준
- React 19 + TypeScript + Tailwind CSS 4
- 같은 코드가 Vite와 Next(App Router)에서 동작한다. 모든 데모를 Next로 빌드해 확인한다.
- 색·모서리·글꼴은 토큰 하나(`tokens.css`)로 바꾼다. [색상](#/docs/colors)
