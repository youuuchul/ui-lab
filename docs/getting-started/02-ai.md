# AI로 설치
설정 프롬프트를 AI 코딩 도구에 붙여 넣으면 프로젝트에 맞춰 설치하고 사용 규칙을 남긴다.

## 디자인 시스템 설정
적용할 프로젝트를 Claude Code·Cursor 같은 AI 도구에서 열고 아래 프롬프트를 그대로 보낸다. 파일 수정과 패키지 설치 권한이 필요하다.

```text
youuuchul's UI Lab 디자인 시스템을 이 프로젝트에 설정해줘.

1. https://youuuchul.github.io/ui-lab/llms.txt 를 읽고 컴포넌트·적용 사례 목록과 설치 방법을 파악한다.
2. 이 프로젝트가 React + Tailwind CSS 4인지 확인한다. Tailwind가 없거나 3이면 설치·이전 계획을 먼저 보여주고 내 확인을 받는다.
3. 토큰을 설치한다: npx shadcn@latest add https://youuuchul.github.io/ui-lab/r/tokens.json
   전역 CSS에서 @import "tailwindcss"; 다음 줄에 생성된 ui-lab-tokens.css 를 import한다.
4. 컴포넌트는 필요할 때만 설치한다: npx shadcn@latest add https://youuuchul.github.io/ui-lab/r/<name>.json
   설치 위치는 components/ui-lab/ 아래 원래 폴더 구조를 유지한다(적용 사례가 상대 경로로 컴포넌트를 불러온다).
5. 프로젝트 규칙 파일(CLAUDE.md 또는 AGENTS.md)에 아래 규칙을 추가한다.
   - UI를 만들 때 llms.txt 목록에서 맞는 컴포넌트를 먼저 찾고, 없을 때만 새로 만든다.
   - 색·모서리·글꼴은 ui-lab 토큰(bg, surface, line, fg, muted, accent, radius-card)을 쓴다.
   - "use client"를 유지하고 next/link·next/image 대신 a·img를 쓴 원본 코드를 고치지 않는다. 프레임워크 기능이 필요하면 바깥에서 감싼다.
6. 끝나면 설치한 파일, 바뀐 설정, 추가한 규칙을 보고한다.
```

## 설치 후 사용
한 번 설정한 프로젝트에서는 이렇게 요청하면 된다. AI가 저장된 규칙과 목록을 보고 컴포넌트를 골라 쓴다.

```text
UI Lab 써서 알림 설정 페이지 만들어줘. 토글이랑 토스트 쓰고.
```

```text
UI Lab의 캐릭터 대화 화면을 가져와서 우리 채팅 API에 연결해줘.
```
