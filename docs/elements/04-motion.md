# 모션
움직임은 상태가 바뀐 이유를 보여줄 때만 쓴다. 장식으로 반복하지 않는다.

## 시간
| 용도           | 시간      | 곡선                 | 쓰인 곳                                                                                                |
|----------------|-----------|----------------------|--------------------------------------------------------------------------------------------------------|
| 색·투명도 변화 | 200ms     | 기본                 | [흐려지는 채팅 말풍선](#/components/chat-bubble)                                                       |
| 이미지 교체    | 300ms     | 기본                 | [크로스페이드 이미지 스택](#/components/crossfade-image-stack)                                         |
| 등장           | 700ms     | `[0.32, 0.72, 0, 1]` | [마스크 텍스트 등장](#/components/rise-text)                                                           |
| 퇴장           | 280ms     | `[0.5, 0, 0.75, 0]`  | 마스크 텍스트 등장                                                                                     |
| 시간 흐름      | 실제 시간 | linear               | [세그먼트 프로그레스](#/components/segmented-progress), [원형 카운트다운](#/components/countdown-ring) |

퇴장은 등장보다 짧게. 사라지는 것을 기다리게 하지 않는다.

## 구현 방식
| 방식                           | 언제                          | 예                                                                |
|--------------------------------|-------------------------------|-------------------------------------------------------------------|
| CSS transition                 | 상태 두 개 사이               | 투명도, 색, 버튼 눌림 `active:scale-90`                           |
| Web Animations API             | 시작·끝을 코드로 알아야 할 때 | 세그먼트 프로그레스(끝나면 다음 칸)                               |
| motion (variants)              | 여러 요소의 순서가 있는 전환  | 마스크 텍스트 등장                                                |
| requestAnimationFrame + 스프링 | 끌기·관성                     | [원형 3D 캐러셀](#/components/service-carousel)                   |
| Canvas / WebGL                 | 수백 개 점·3D                 | [3D 역량 그래프 히어로](#/blocks/force-graph-hero), 은하수 글로브 |

## 모션 줄이기
`prefers-reduced-motion`이면 위치 이동·회전을 끄고 결과 상태만 보여준다. 렌더 루프가 있는 컴포넌트는 화면 밖에서 멈춘다.
