# 색상
어두운 바탕 위에 회색 단계와 포인트 색 하나로 위계를 만든다.

## 토큰
| 토큰      | 값        | 쓰임                       |
|-----------|-----------|----------------------------|
| `bg`      | `#111111` | 페이지 바탕                |
| `surface` | `#1b1b1b` | 카드, 패널, 입력창 바탕    |
| `line`    | `#2a2a2a` | 테두리, 구분선             |
| `fg`      | `#f2f2f2` | 본문 글자, 선택 상태       |
| `muted`   | `#8c8c8c` | 보조 글자, 비활성 아이콘   |
| `accent`  | `#6b8cff` | 주요 행동, 진행, 내 메시지 |

Tailwind 클래스로 그대로 쓴다: `bg-surface`, `text-muted`, `border-line`, `bg-accent`.

## 투명도로 단계 만들기
같은 색에 투명도를 붙여 단계를 만든다. 새 회색을 추가하지 않는다.

| 단계      | 클래스                         | 예                                                     |
|-----------|--------------------------------|--------------------------------------------------------|
| 호버 바탕 | `bg-fg/10`                     | 아이콘 버튼, 사이드바 선택                             |
| 약한 칸   | `bg-fg/5` · `bg-white/10`      | 칩, 입력창                                             |
| 빈 트랙   | `bg-fg/25`                     | [세그먼트 프로그레스](#/components/segmented-progress) |
| 보조 글자 | `text-fg/80` · `text-white/60` | 지문, 설명                                             |

## 상태 색
포인트 색과 겹치지 않는 Tailwind 기본 색을 쓴다.

| 상태           | 클래스                                   | 쓰인 곳                                                 |
|----------------|------------------------------------------|---------------------------------------------------------|
| 경고·시간 임박 | `red-400`                                | [원형 카운트다운](#/components/countdown-ring) 20% 미만 |
| 시스템 알림    | `yellow-500/20` 바탕 + `yellow-200` 글자 | [흐려지는 채팅 말풍선](#/components/chat-bubble) system |
| 성공·권장      | `emerald-300`                            | 문서의 Do                                               |

## 이미지 위 글자
캐릭터·사진 배경 위에서는 대비가 계속 바뀐다. 두 가지로 읽기를 보장한다.
- 바탕 반투명 + 블러: `bg-zinc-950/80 backdrop-blur-md` ([캐릭터 대화 화면](#/blocks/chat-scene)의 말풍선)
- 글자 그림자: 바탕 없는 지문에 `0 1px 3px` 검정 그림자

## 브랜드 바꾸기
`tokens.css`의 값만 바꾸면 모든 컴포넌트에 반영된다. 밝은 바탕으로 바꿀 때는 `fg`/`bg`를 뒤집고 `text-white`를 쓴 이미지 위 컴포넌트(채팅 계열)는 그대로 둔다.
