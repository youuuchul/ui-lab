# 글쓰기
화면 문구는 짧게, 한 번만.

## 원칙
- 버튼은 동작으로 끝낸다: "보내기", "다시 불러오기".
- 상태 문구는 명사형으로 짧게: "불러오는 중", "시간 종료", "완료".
- 같은 정보를 두 곳에 쓰지 않는다. 의도는 구분선·색·위치로 보인다.
- 안내 문장이 꼭 필요하면 한 화면에 한 곳, 한 줄.
- 화면에 개발자 정보(명령어, 파일 경로, 함수명)를 쓰지 않는다. 문서에만 둔다.

## 예
### 로딩
- 쓴다: 불러오는 중
- 피한다: 잠시만 기다려 주세요! 데이터를 불러오고 있어요

### 빈 입력창
- 쓴다: 메시지 입력
- 피한다: 여기에 메시지를 입력하세요...

### 입력 잠금
- 쓴다: 시간 종료
- 피한다: 대화 시간이 모두 끝났습니다. 다음 라운드를 기다려 주세요

## 아이콘 버튼
글자 없는 버튼은 `aria-label`과 `title`을 같은 말로 단다. 화면 읽기와 마우스 툴팁이 같아진다.

## 캐릭터 대화
대사와 지문을 나눈다. 지문은 `*행동*` 표기로 받고 [흐려지는 채팅 말풍선](#/components/chat-bubble)이 기울임체로 따로 그린다.
