# 간격과 모서리
4px 단위 간격, 크기별로 다른 모서리.

## 간격
| 값      | 클래스          | 쓰임                                |
|---------|-----------------|-------------------------------------|
| 6px     | `gap-1.5`       | 칩·버튼 묶음, 말풍선 안 대사와 지문 |
| 8px     | `gap-2`         | 입력창의 버튼 사이, 말풍선 사이     |
| 16px    | `gap-4` · `p-4` | 카드 사이, 패널 안쪽                |
| 20~24px | `p-5` · `p-6`   | 카드·미리보기 안쪽                  |
| 56px    | `mt-14`         | 문서 섹션 사이                      |

## 모서리
| 대상                         | 값                          |
|------------------------------|-----------------------------|
| 카드, 미리보기               | `rounded-card` (20px)       |
| 말풍선, 입력창, 패널         | `rounded-2xl` (16px)        |
| 칩, 아이콘 버튼, 보내기 버튼 | `rounded-full`              |
| 작은 버튼, 탭                | `rounded-lg` · `rounded-md` |

말풍선은 말하는 쪽 아래 모서리만 `rounded-br-sm`/`rounded-bl-sm`으로 줄여 방향을 보인다.

## 터치 영역
누르는 요소는 36px 이상. 입력창 옆 원형 버튼은 `h-9 w-9`(36px).
