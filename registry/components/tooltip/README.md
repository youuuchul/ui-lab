# 툴팁

아이콘 버튼에 마우스를 올리거나 포커스하면 이름과 단축키를 짧게 보여주는 말풍선.

## Props
| 이름       | 타입                | 기본값  | 설명                            |
|------------|---------------------|---------|---------------------------------|
| `content`  | `string`            | -       | 한 줄 설명                      |
| `children` | `ReactElement`      | -       | 트리거 하나. 포커스 가능한 요소 |
| `side`     | `"top" \| "bottom"` | `"top"` | 표시 위치                       |
| `delay`    | `number`            | `300`   | 마우스 호버 후 열리기까지(ms)   |

## 접근성
- 트리거에 `aria-describedby`를 자동으로 붙여 `role="tooltip"` 내용을 설명으로 읽게 한다. 아이콘 버튼의 이름은 따로 `aria-label`로 준다.
- 키보드 포커스(`:focus-visible`)는 바로 열리고, Esc로 닫힌다.
- 터치(`pointerType`이 mouse가 아님)로는 열지 않는다. 탭할 때마다 툴팁이 깜빡이지 않게 하려는 것이다.

## 구현 메모
- 위치는 트리거 기준 `absolute`로 잡는다. 화면 가장자리에서 뒤집기·밀어내기는 하지 않는다. 필요하면 Floating UI 같은 위치 계산 라이브러리로 바꾼다.
- 닫힌 상태도 DOM에 남겨 두고(`invisible`) `aria-describedby` 참조가 늘 유효하게 한다.
