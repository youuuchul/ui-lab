# 토스트 기능 명세
동작 결과를 화면 하단에 잠깐 알리고 스스로 사라지는 메시지. 실행 취소 버튼을 붙일 수 있다.

## 목적
- 삭제·저장 같은 동작의 결과를 흐름을 끊지 않고 알린다.
- 되돌릴 수 있는 동작에는 그 자리에서 실행 취소 기회를 준다.

## 사용자 시나리오
1. 사용자가 메모 "장보기 목록"을 삭제하면 목록에서 빠지고 "'장보기 목록'을 삭제했어요"와 "실행 취소"가 뜬다.
2. 사용자가 "실행 취소"를 누르면 메모가 원래 자리로 돌아오고 토스트가 닫힌다.
3. 저장 요청이 실패하면 붉은 오류 토스트가 "저장하지 못했어요. 네트워크를 확인해 주세요"를 알린다.

## 상태
| 상태     | 화면           | 들어오는 조건           | 나가는 조건               |
|----------|----------------|-------------------------|---------------------------|
| 닫힘     | 없음(DOM 제외) | open=false              | open=true                 |
| 열림     | 하단 메시지    | open=true               | 시간 경과·액션·open=false |
| 일시정지 | 열림 유지      | 포인터 올림·내부 포커스 | 포인터·포커스 벗어남      |
| 오류     | 붉은 바탕      | tone="error"            | tone 변경                 |

- 열림은 `duration`(기본 3000ms) 뒤 자동으로 닫힌다. `0`이면 닫히지 않는다.
- 닫힐 때 0.15초 동안 내려가며 사라진 뒤 DOM에서 빠진다.

## 동작
- 열림/닫힘은 쓰는 쪽이 `open`으로 쥔다. 자동 닫힘·액션 후에는 `onOpenChange(false)`를 호출한다.
- "action" 버튼 클릭: `action.onClick`을 실행하고 `onOpenChange(false)`를 호출한다.
- 마우스를 올리거나 토스트 안 요소에 포커스가 있는 동안은 자동 닫힘 타이머가 멈추고, 벗어나면 `duration`부터 다시 센다.
- 열리거나 닫힐 때마다 일시정지는 풀린다.
- `message`가 바뀌면 타이머를 처음부터 다시 센다. 같은 토스트를 새 메시지로 바꿔 쓴다.
- 기본은 `role="status"`·`aria-live="polite"`, 오류는 `role="alert"`·`assertive`다.
- `scope="viewport"`는 화면 하단 고정, `scope="parent"`는 가장 가까운 relative 부모 하단이다.
- 액션 버튼은 터치 40px 이상이다. 동작 줄이기에서는 이동·페이드 전환이 없다.

## 예외
- 토스트는 한 개만 그린다. 여러 개를 쌓는 큐는 없고, 새 메시지는 쓰는 쪽에서 같은 인스턴스의 `message`를 바꾼다.
- 닫기 버튼과 Esc 닫기는 없다. 자동 닫힘이나 액션으로만 닫힌다.
- `duration=0`이면 직접 `open`을 끄기 전에는 남는다.
- 실행 취소 후 데이터 복원은 쓰는 쪽에서 구현한다.
- 꼭 처리해야 하는 오류(결제 실패 등)는 화면 안에 남는 안내로 쓴다. 토스트만으로 알리지 않는다.

## 인수 조건
- Given `open=true`·`duration=3000`, When 포인터를 올리지 않고 3초가 지난다, Then `onOpenChange(false)`가 호출되고 토스트가 사라진다.
- Given 토스트가 열림, When 마우스를 올리고 3초 넘게 둔다, Then 닫히지 않는다. 벗어나면 3초 뒤 닫힌다.
- Given "실행 취소" 액션이 있음, When 액션을 클릭한다, Then `action.onClick`이 실행되고 토스트가 닫힌다.
- Given `tone="error"`, When 렌더한다, Then 붉은 바탕이고 `role="alert"`로 읽힌다.
- Given `duration=0`, When 10초가 지난다, Then 토스트가 그대로 남아 있다.
- Given 토스트가 열린 채 `message`가 바뀜, When 변경 시점부터 `duration`이 지난다, Then 그때 닫힌다.

## 측정
- `toast_shown` { toast_type: "default" | "error", has_action, trigger }
- `toast_action_clicked` { action_label, trigger }
- `toast_dismissed` { reason: "timeout" | "action" | "programmatic" } : 닫힘 원인은 쓰는 쪽이 구분해서 남긴다.

## 범위 밖
- 토스트 큐·쌓기·우선순위, 프로바이더·전역 호출 함수.
- 닫기 버튼, 스와이프로 닫기.
- 실행 취소로 되돌리는 데이터 처리.
- 성공·정보·경고 톤(기본·오류 두 가지만 있다).
