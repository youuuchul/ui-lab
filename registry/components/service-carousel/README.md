# 원형 3D 캐러셀

항목을 원 둘레에 세워 두고 가운데가 선택이 되는 캐러셀. 양옆 항목은 비스듬히 돌아 무대 끝에 걸쳐 보인다. 끝이 없이 돈다.

## Props
| 이름           | 타입                          | 기본값   | 설명                                                                |
|----------------|-------------------------------|----------|---------------------------------------------------------------------|
| `items`        | `T[]`                         | -        | 항목                                                                |
| `getKey`       | `(item) => string`            | -        | key                                                                 |
| `renderItem`   | `(item, active) => ReactNode` | -        | 항목 내용. 크기는 캐러셀이 정함                                     |
| `onOpen`       | `(item) => void`              | -        | 가운데 항목 클릭·Enter·Space                                        |
| `onChange`     | `(index) => void`             | -        | 가운데 항목이 바뀔 때                                               |
| `ratio`        | `number`                      | `1.5`    | 항목 높이 / 폭                                                      |
| `maxItemWidth` | `number`                      | `260`    | 항목 폭 상한(px). 무대 높이 84%·폭 62%도 함께 제한                  |
| `autoplay`     | `number`                      | `5000`   | 자동 넘김 간격(ms), `0`이면 끔                                      |
| `pointerLabel` | `string`                      | -        | 가운데 항목 위에서 커서 대신 따라다니는 라벨 (`onOpen`이 있을 때만) |
| `label`        | `string`                      | `"목록"` | 접근성 라벨                                                         |
| `className`    | `string`                      | `""`     | 바깥 크기 지정 (높이 필수)                                          |

## 조작
- 끌기: 가로로 8px 넘게 움직여야 끌기로 본다. 세로가 먼저면 페이지 스크롤에 양보한다. 놓을 때 34px 넘게 움직였거나 빠르게 튕기면 1칸(아주 빠르면 2칸) 넘긴다.
- 탭: 가운데 항목 = 열기, 옆 항목 = 그 항목으로 이동, 무대 왼쪽·오른쪽 30% 빈 곳 = 한 칸.
- 가로 휠(트랙패드 좌우), 화살표 키, 이전·다음 버튼.
- 자동 넘김은 마우스를 올렸거나 무대가 화면에 절반 미만으로 보이거나 모션 줄이기면 멈춘다. 키보드 포커스가 캐러셀 안에 있으면 멈추고, 끄는 중이면 한 번 미룬다.

## 구현 메모
- 위치 `L`이 목표 `T`를 스프링(`dt × 11`)으로 따라가고, 매 프레임 `transform`·`opacity`·`z-index`를 직접 쓴다 (React 렌더 없음). 바뀐 값만 쓴다.
- 옆 항목 거리 = `min(무대 폭 × 0.46, 항목 폭 × 2)`. 넓고 낮은 무대에서 너무 벌어지지 않는다.
- 넘기는 속도에 따라 살짝 기울고(lean), 마우스 위치로 가운데 항목이 포인터 쪽으로 돈다.
- 3D 변형 때문에 이벤트 대상이 어긋나서 클릭 판정은 좌표로 가장 앞쪽 항목을 고른다.
- 원본(웹 포트폴리오 서비스 섹션)의 WebGL 폰 무대, 휴대폰 기울기, 상세 화면 전환·주소 연동은 뺐다. 폰 모양은 `blocks/phone-3d`를 `renderItem`에 넣어 쓴다.
- 의존성: `motion` (모션 줄이기 감지만).
