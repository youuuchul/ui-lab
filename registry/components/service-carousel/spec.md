# 원형 3D 캐러셀 기능 명세
항목을 원 둘레에 세우고 가운데가 선택이 되는 캐러셀.

## 목적
- 서비스·작품처럼 5~10개 항목을 한 번에 훑고, 가운데 항목 하나를 골라 열게 한다.
- 끌기·휠·키보드·버튼을 모두 열어 둔다. (출처: 포트폴리오 사이트 서비스 섹션)

## 사용자 시나리오
1. 방문자가 서비스 카드들이 원 둘레에 돈 모양을 보고, 가운데 카드를 눌러 상세를 연다.
2. 방문자가 끌거나 트랙패드 좌우 스크롤, 화살표로 다음 카드로 넘긴다.
3. 아무것도 하지 않으면 5초마다 자동으로 한 칸씩 넘어간다.

## 상태
| 상태         | 화면                                | 들어오는 조건                             | 나가는 조건         |
|--------------|-------------------------------------|-------------------------------------------|---------------------|
| 정지(가운데) | 한 항목이 앞에 서고 양옆은 비스듬함 | 마운트, 이동이 멈춤                       | 이동 입력·자동 넘김 |
| 이동 중      | 스프링으로 다음 위치로 돎           | 입력 또는 자동 넘김                       | 목표 위치에 도달    |
| 끄는 중      | 손가락·마우스를 따라 움직임         | 가로로 8px 넘게 끌기 시작                 | 포인터를 놓음, 취소 |
| 자동 넘김    | 5초마다 한 칸                       | `autoplay > 0`, 화면에 절반 이상          | 아래 멈춤 조건      |
| 자동 멈춤    | 넘어가지 않음                       | 호버, 키보드 포커스, 화면 밖, 모션 줄이기 | 조건 해제           |

- 멈춤 조건은 마우스 호버, 키보드 포커스가 안에 있음, 무대가 화면에 절반 미만 보임, 모션 줄이기다.
- 끄는 중에 자동 넘김 시간이 되면 한 번 미룬다.
- 목록은 끝이 없이 돈다. 마지막 다음은 처음이다.

## 동작
- 끌기: 가로로 8px 넘게, 세로보다 가로가 클 때 끌기로 본다. 세로가 먼저면 페이지 스크롤에 양보한다. 놓을 때 34px 넘게 움직였거나 빠르게 튕기면 1칸(아주 빠르면 2칸) 넘긴다.
- 탭(8px 미만): 가운데 항목은 `onOpen`, 옆 항목은 그 항목으로 이동, 무대 왼쪽·오른쪽 30% 빈 곳은 한 칸 이동. 판정은 좌표로 가장 앞쪽 항목을 고른다.
- 가로 휠(트랙패드 좌우): 누적 40을 넘으면 한 칸, 450ms 동안 추가 입력은 무시한다. 세로 휠은 페이지 스크롤에 넘긴다.
- 키보드: 무대에 포커스한 상태에서 좌우 화살표로 한 칸, Enter·Space로 가운데 항목 `onOpen`.
- 버튼: 좌우 "이전"·"다음" 버튼으로 한 칸. 40×40px.
- 마우스 호버: 가운데 항목이 포인터 쪽으로 기운다. `pointerLabel`과 `onOpen`이 있으면 가운데 항목 위에서 커서 대신 라벨이 따라다닌다. 옆 항목 위는 포인터 모양만 바뀐다.
- `onChange(index)`: 가운데 항목이 바뀔 때 호출한다.
- `renderItem(item, active)`: 가운데 항목만 `active=true`다. 항목 크기는 캐러셀이 정한다.
- 가운데가 아닌 항목은 `aria-hidden`이고, 무대는 `role="group"`, `aria-roledescription="carousel"`, `label`을 가진다.

## 예외
- `items`가 비어 있음: 아무것도 그리지 않는다.
- 항목이 1~2개: 처리하지 않는다. 원형 배치가 어색해진다. 쓰는 쪽에서 5개 이상일 때만 쓴다.
- `className`에 높이가 없음: 무대 높이가 0이라 보이지 않는다. 쓰는 쪽에서 높이를 지정한다.
- `onOpen` 없음: 가운데 탭·Enter가 동작하지 않고, `pointerLabel`도 표시되지 않는다.
- 카드 안의 가로 스크롤: 제스처가 겹친다. 쓰는 쪽에서 넣지 않는다.
- 모션 줄이기: 자동 넘김, 스프링 이동, 기울기·호버 기울임을 끈다.
- 카드 안 링크·버튼: 가운데가 아닌 카드는 `aria-hidden`이라 접근되지 않는다. 쓰는 쪽에서 `onOpen`으로 이동을 처리한다.
- 항목의 `getKey`가 중복: 처리하지 않는다. 쓰는 쪽에서 고유 키를 준다.
- 상세 화면 전환, 주소 연동: 원본에서 뺐다. 쓰는 쪽에서 처리한다.

## 인수 조건
- Given 5개 항목, 가운데 index 0, When 다음 버튼을 누른다, Then 가운데가 index 1이 되고 `onChange(1)`이 호출된다.
- Given 마지막 항목이 가운데, When 다음 버튼을 누른다, Then 첫 항목이 가운데가 된다.
- Given 가운데 항목, When 클릭 또는 Enter, Then `onOpen(가운데 항목)`이 호출된다.
- Given 옆 항목, When 클릭한다, Then 그 항목이 가운데로 오고 `onOpen`은 호출되지 않는다.
- Given 마우스로 가로 50px 끌고 놓음, When 놓는다, Then 오른쪽에서 왼쪽으로 끌었으면 다음, 반대면 이전 항목으로 한 칸 넘어간다.
- Given 세로로 먼저 움직이는 터치, When 8px 넘게 움직인다, Then 끌기가 시작되지 않고 페이지가 스크롤된다.
- Given `autoplay=5000`, 화면에 절반 이상 보임, When 5초간 입력이 없다, Then 한 칸 넘어간다. 마우스를 올리면 넘어가지 않는다.
- Given `autoplay=0`, When 오래 둔다, Then 자동으로 넘어가지 않는다.

## 측정
- `carousel_item_changed` { from_index, to_index, trigger: "drag" | "wheel" | "key" | "button" | "tap" | "autoplay" } : `onChange`에서 남긴다. `trigger`는 컴포넌트가 주지 않아 쓰는 쪽이 입력 핸들러에서 구분하거나 생략한다.
- `carousel_item_opened` { item_id, index } : `onOpen`에서 남긴다.
