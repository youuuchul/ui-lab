# 버튼 기능 명세
동작을 실행하는 기본 버튼. 위계에 따라 네 가지 모양과 세 가지 크기를 쓴다.

## 목적
- 한 영역에서 무엇이 주 동작인지 모양으로 구분해 보여준다.
- 시간이 걸리는 동작의 중복 클릭을 막고, 진행 중임을 알린다.

## 사용자 시나리오
1. 글 작성자가 "게시"(primary)를 누르면 버튼이 로딩으로 바뀌고, 끝나면 "게시했어요" 문구와 함께 비활성이 된다.
2. 작성자가 "삭제"(danger)를 누르면 "정말 삭제"와 "취소"가 나란히 나타난다.
3. 키보드 사용자가 Tab으로 버튼에 들어가 Enter·Space로 실행한다.

## 상태
| 상태   | 화면                  | 들어오는 조건 | 나가는 조건           |
|--------|-----------------------|---------------|-----------------------|
| 기본   | variant 색            | 초기          | 호버·누름·로딩·비활성 |
| 호버   | 배경 한 단계 진해짐   | 포인터 올림   | 포인터 벗어남         |
| 누름   | 0.96배 축소           | 누르는 동안   | 뗌                    |
| 포커스 | 바깥 링               | 키보드 포커스 | 포커스 이동           |
| 로딩   | 스피너, 라벨 숨김     | loading=true  | loading=false         |
| 비활성 | 투명도 45%, 금지 커서 | disabled=true | disabled=false        |

- 로딩 중에도 폭은 라벨 폭 그대로이고 포커스는 유지된다(`aria-disabled`).
- 비활성은 네이티브 `disabled`라 포커스를 받지 못한다.
- 로딩과 비활성이 함께면 비활성이 우선이다.

## 동작
- 클릭·Enter·Space: `onClick` 호출. `type` 기본값은 `button`이라 폼을 제출하지 않는다. 제출은 `type="submit"`을 넘긴다.
- 로딩 중 클릭·Enter·Space: `onClick`을 호출하지 않고 기본 동작도 막는다. 제출 버튼이어도 제출되지 않는다.
- 로딩이 되면 스피너를 겹치고 라벨은 `invisible`로 숨겨 폭이 유지된다. 스크린리더에는 "처리 중"을 읽는다(`aria-busy`).
- `fullWidth`면 부모 폭을 채운다. `leadingIcon`·`trailingIcon`은 라벨 앞뒤에 놓인다.
- `size=sm`은 높이 32px이고 위아래 투명 영역으로 터치 영역을 40px로 맞춘다.
- 동작 줄이기에서는 눌림 축소와 색 전환이 없고 스피너도 돌지 않는다.

## 예외
- 연속 클릭: 컴포넌트가 막지 않는다. 막으려면 쓰는 쪽에서 `loading` 또는 `disabled`를 먼저 켠다.
- 실패: 컴포넌트는 로딩만 다룬다. 오류 안내와 로딩 해제는 쓰는 쪽에서 처리한다.
- 아이콘만 있는 버튼: 쓰는 쪽에서 `aria-label`을 넘긴다.
- 확인 단계: 삭제 같은 되돌릴 수 없는 동작의 확인 흐름은 쓰는 쪽에서 만든다(데모는 "삭제"→"정말 삭제").

## 인수 조건
- Given 기본 버튼, When 클릭한다, Then `onClick`이 한 번 호출된다.
- Given `loading=true`, When 클릭하거나 Enter를 누른다, Then `onClick`이 호출되지 않고 버튼에 포커스가 남는다.
- Given `loading`이 false에서 true로 바뀜, When 화면을 본다, Then 스피너가 보이고 버튼 너비가 이전과 같다.
- Given `loading=true`, When 스크린리더로 읽는다, Then "처리 중"이 읽히고 `aria-busy`가 true다.
- Given `disabled=true`, When Tab으로 이동한다, Then 버튼에 포커스가 가지 않는다.
- Given `<form>` 안의 기본 버튼, When 클릭한다, Then 폼이 제출되지 않는다.

## 측정
- `button_clicked` { button_id, variant, location }
- `button_action_failed` { button_id, reason } : 로딩 뒤 실패를 쓰는 쪽에서 남길 때
- 로딩 시작·종료 시각은 쓰는 쪽 동작 이벤트(예: `post_publish_started`·`post_publish_completed`)에 함께 남긴다.

## 범위 밖
- 링크 이동(`a` 태그): 쓰는 쪽에서 링크 컴포넌트를 쓴다.
- 확인 대화상자, 실패 안내, 중복 요청 방지 로직.
- 아이콘 전용 버튼의 접근성 이름.
- 토글처럼 켜짐·꺼짐을 가지는 버튼.
