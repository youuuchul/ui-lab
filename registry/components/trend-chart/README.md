# 추이 선 차트

구간별 값을 선으로 잇고 전기를 점선으로 겹치는, 키보드로도 값을 읽는 추이 차트.

데모 수치는 PlaceWave의 가상 플랫폼 데이터(시나리오로 생성한 합성 데이터)이며 실제 서비스 데이터가 아니다.

## Props
| 이름      | 타입                                               | 기본값             | 설명                                                           |
|-----------|----------------------------------------------------|--------------------|----------------------------------------------------------------|
| `title`   | `string`                                           | -                  | 차트 이름. 요약 문장과 대체 표 제목에 쓴다                     |
| `labels`  | `string[]`                                         | -                  | 구간 이름. "9/1~9/7"이면 축에는 앞부분만, 툴팁에는 전체를 쓴다 |
| `series`  | `{ label; values: (number \| null)[]; dashed? }[]` | -                  | 선 목록. `dashed`는 전기 같은 참고선                           |
| `format`  | `(v: number) => string`                            | 천 단위 쉼표       | 축·툴팁·표 값 표시                                             |
| `summary` | `string`                                           | 첫 선의 처음·끝 값 | 스크린리더 요약                                                |
| `height`  | `number`                                           | `220`              | 높이(px)                                                       |

## 구현 메모
- 차트 라이브러리 없이 SVG로 그린다. 폭은 `ResizeObserver`로 재고, y축 최대값은 4칸으로 나눠 떨어지는 값으로 올린다.
- 차트 영역이 `role="img"` + 요약 `aria-label`이고 포커스를 받는다. 좌우 화살표·Home·End로 구간을 옮기면 세로선과 툴팁이 뜨고, 같은 내용을 `aria-live` 문장으로 읽는다. Esc로 닫는다.
- 포인터를 올려도 가까운 구간의 툴팁이 뜬다. 툴팁은 차트 가운데를 넘으면 왼쪽으로 뒤집어 영역 밖으로 나가지 않는다.
- 실선은 색과 함께 점 모양(원·네모·마름모)으로, 참고선은 점선으로 구분한다. 31구간이 넘으면 점은 마지막 구간과 가리킨 구간에만 그려 범례 모양과 선을 잇는다.
- 같은 값을 `sr-only` 표로도 둔다.
