# 추이 선 차트 기능 명세
구간별 값을 선으로 잇고 전기를 점선으로 겹치는, 키보드로도 값을 읽는 추이 차트.

## 목적
- 스코어보드의 증감이 "언제" 생겼는지 구간별로 보여준다. (PlaceWave 저장소/docs/dashboard.md §3b 개요 탭 추이 카드)
- 같은 구간의 직전 기간 값을 점선으로 겹쳐 계절·요일 효과와 실제 변화를 가른다. (같은 문서, 전기 규칙)

## 사용자 시나리오
1. 운영자가 주별 결제 선에 포인터를 올려 "9/7~9/13 결제 1,367 · 전기 1,488"을 확인한다.
2. 키보드 사용자가 차트에 포커스한 뒤 오른쪽 화살표로 구간을 옮기며 값을 듣는다.
3. 스크린리더 사용자가 요약 문장과 대체 표로 전체 값을 읽는다.

## 상태
| 상태      | 화면                               | 들어오는 조건                | 나가는 조건                   |
|-----------|------------------------------------|------------------------------|-------------------------------|
| 기본      | 선, 범례, 점(31구간 초과면 끝점만) | 마운트                       | 포인터 진입, 포커스 후 화살표 |
| 구간 선택 | 세로선, 선마다 점, 툴팁            | 포인터 이동, 화살표·Home·End | 포인터 이탈, 포커스 이탈, Esc |
| 선 끊김   | 값 없는 구간에 선이 없음           | `values`에 null              | 값 채움                       |

- `labels`가 바뀌면(기간 전환) 선택을 지운다.

## 동작
- 포인터: 가로 위치에서 가장 가까운 구간을 고른다.
- 키보드: 차트가 탭 순서에 있다. ←→ 한 칸, Home·End 처음·끝, Esc 닫기. 고른 구간은 `aria-live`로 "9/7~9/13: 결제 1,367, 신청 2,718, 전기 결제 1,488"처럼 읽는다.
- 툴팁은 세로선 오른쪽에 뜨고, 차트 가운데를 넘으면 왼쪽으로 뒤집는다.
- y축은 0부터 시작하고 최대값을 4칸으로 나눠 떨어지는 값으로 올린다.
- x축 라벨은 폭에 맞춰 건너뛰고 마지막 구간은 항상 적는다. "8/24~8/30"은 축에 "8/24"만 적는다.
- 터치 기기에서는 가로 드래그로 구간을 고르고 세로 스크롤은 막지 않는다.

## 예외
- 모든 값이 0이거나 비어 있으면 y축 최대값을 1로 둔다.
- 전기가 데이터 범위 밖이면 쓰는 쪽에서 점선 시리즈를 빼고 머리에 "전기 없음"을 적는다. (dashboard.md §3b)
- 차트 클릭 드릴다운(구간 → 그 기간으로 이동), 입자 토글(일·주·월): 쓰는 쪽에서 처리한다.

## 인수 조건
- Given 3개 시리즈 중 1개 `dashed`, When 렌더한다, Then 범례에 실선 2개(원·네모 점)와 점선 1개가 보인다.
- Given 차트 포커스, When → 를 누른다, Then 첫 구간이 선택되고 툴팁과 live 문장이 나온다.
- Given 마지막 구간 선택, When → 를 누른다, Then 마지막 구간에 머문다.
- Given `values`에 null, When 렌더한다, Then 그 구간에서 선이 끊기고 툴팁·표에는 "—"가 보인다.
- Given 90구간, When 렌더한다, Then 점은 각 실선의 마지막 구간에만 있고 x축 라벨이 겹치지 않는다.

## 측정
- `trend_point_inspected` { chart_id, bucket, input: "pointer" | "keyboard" } (가정): 구간을 고를 때. 짧은 시간에 여러 번 나오므로 세션당 첫 1회만 남긴다.

## 범위 밖
- 이중 y축, 막대·누적 막대
- 확대·이동
- 실험 구간 표식 (원본도 검색 탭에서는 두지 않는다)
