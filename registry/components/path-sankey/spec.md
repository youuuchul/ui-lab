# 생키 다이어그램 기능 명세
세션이 화면에서 화면으로 넘어가는 흐름을 열별 노드와 띠 두께로 보여주는 생키 다이어그램.

## 목적
- 퍼널 숫자로 좁힌 이탈 지점에서 "어떤 경로로" 빠지는지 본다. (PlaceWave 저장소/docs/dashboard.md §2 퍼널 탭 드릴다운 ② 경로 탐색 생키)
- 경로 비중을 화면 세션 중·전체 세션 대비 두 기준으로 읽는다. (같은 문서 §3a 경로 비중)

## 사용자 시나리오
1. 기획자가 2번째 화면의 이탈 노드가 큰 것을 보고, 어떤 랜딩에서 온 이탈인지 띠에 포인터를 올려 확인한다.
2. 키보드 사용자가 차트에 포커스한 뒤 화살표로 "행사 상세 · 2번째 화면"에 가서 다음 화면 상위 3개를 듣는다.

## 상태
| 상태      | 화면                                      | 들어오는 조건         | 나가는 조건                   |
|-----------|-------------------------------------------|-----------------------|-------------------------------|
| 기본      | 모든 띠 옅게, 노드 이름·세션 수           | 마운트                | 포인터 진입, 화살표           |
| 띠 강조   | 그 띠만 진하게 + 띠 툴팁                  | 띠에 포인터           | 다른 대상, 포인터 이탈        |
| 노드 강조 | 연결된 띠 진하게, 노드 테두리 + 노드 툴팁 | 노드에 포인터, 화살표 | 포인터 이탈, 포커스 이탈, Esc |

## 동작
- 노드 값: 0열은 step 1 링크의 출발 합, 그 뒤 열은 도착 합.
- 노드 순서: 값 내림차순, `otherLabel`은 그 아래, `exitLabel`은 맨 아래 회색.
- 띠 툴팁: 세션, 출발 화면 세션 중 %, 전체 세션(0열 합) 대비 %.
- 노드 툴팁: 세션, 전체 대비 %, 다음 화면 상위 3개와 비중.
- 키보드: ←→ 다른 열의 같은 이름 노드(없으면 맨 위), ↑↓ 같은 열 이웃 노드, Esc 닫기. 고른 노드를 `aria-live`로 읽는다.
- 폭이 `minWidth`보다 좁으면 차트만 가로 스크롤한다.

## 예외
- 앞 열에 없는 화면에서 출발하는 링크는 그리지 않는다.
- 높이 12px 미만 노드는 이름을 생략한다. 툴팁·대체 표에는 있다.
- 화면 이름 묶기(상위 N + 기타), 기간·세그먼트 집계: 쓰는 쪽에서 처리한다.

## 인수 조건
- Given 랜딩 행사 상세 132,937 세션, When 렌더한다, Then 0열 맨 위 노드가 "행사 상세 132,937"이다.
- Given 2번째 화면에 이탈 노드, When 렌더한다, Then 그 열 맨 아래 회색이다.
- Given 차트 포커스, When ↓ 를 두 번 누른다, Then 0열 세 번째 노드가 테두리와 함께 강조되고 툴팁이 뜬다.
- Given 띠에 포인터, When 머문다, Then 그 띠만 진하고 "출발 화면 세션 중 %"가 보인다.

## 측정
- `path_node_inspected` { column, screen, input } (가정): 노드를 고를 때, 세션당 화면별 첫 1회.
- `path_link_inspected` { step, from, to } (가정): 띠를 고를 때.

## 범위 밖
- 띠 클릭 고정(원본은 클릭한 띠를 아래 줄에 고정 표시)
- 노드 드래그 재배치
- 세션 수 집계와 화면 묶기
