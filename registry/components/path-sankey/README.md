# 생키 다이어그램

세션이 화면에서 화면으로 넘어가는 흐름을 열별 노드와 띠 두께로 보여주는 생키 다이어그램.

데모 수치는 PlaceWave의 가상 플랫폼 데이터(시나리오로 생성한 합성 데이터)이며 실제 서비스 데이터가 아니다.

## Props
| 이름         | 타입                                    | 기본값   | 설명                           |
|--------------|-----------------------------------------|----------|--------------------------------|
| `title`      | `string`                                | -        | 차트 이름. 요약과 대체 표 제목 |
| `columns`    | `string[]`                              | -        | 열 이름. `step` 최대값 + 1개   |
| `links`      | `{ step; from; to; value }[]`           | -        | `step` 1은 0열 → 1열           |
| `groups`     | `{ label; color; members: string[] }[]` | -        | 노드 색 묶음과 범례            |
| `exitLabel`  | `string`                                | `"이탈"` | 열 맨 아래 회색 노드           |
| `otherLabel` | `string`                                | `"기타"` | 이탈 바로 위에 두는 노드       |
| `height`     | `number`                                | `420`    | 높이(px)                       |
| `minWidth`   | `number`                                | `640`    | 이보다 좁으면 가로 스크롤      |

## 구현 메모
- 레이아웃을 직접 계산한다. 열마다 노드 합이 가장 큰 열에 맞춰 세로 배율을 정하고, 노드는 값 내림차순(기타·이탈은 아래)으로 쌓는다. 띠는 출발·도착 노드 안에서 상대 노드 위치 순으로 쌓아 교차를 줄인다.
- 띠에 포인터를 올리면 그 띠만 진해지고 세션 수·출발 화면 대비·전체 대비가 뜬다. 노드에 올리면 연결된 띠가 진해진다.
- 차트가 `role="img"`로 포커스를 받고, 화살표로 노드를 옮긴다(좌우 = 열, 위아래 = 같은 열). 노드 툴팁은 다음 화면 상위 3개를 함께 보여주고 `aria-live`로 읽는다.
- 노드 이름·세션 수를 노드 옆에 적어 색 없이도 읽힌다. 높이 12px 미만 노드는 이름을 생략하고 툴팁·대체 표로 본다.
