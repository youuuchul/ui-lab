# 텍스트 필드 기능 명세
라벨·도움말·오류·글자 수를 갖춘 한 줄 입력칸.

## 목적
- 무엇을 쓰는 칸인지, 규칙이 무엇인지, 어디가 틀렸는지를 입력칸 한 곳에서 보여준다.

## 사용자 시나리오
1. 닉네임에 "하"를 입력하면 "2~12자로 입력해 주세요"가 도움말 자리에 오류로 바뀌어 나온다.
2. 이메일을 입력하고 칸을 벗어나면 형식이 틀릴 때 "이메일 형식이 아니에요"가 나온다.
3. 가입 후 바꿀 수 없는 아이디는 비활성 칸으로 값만 보여준다.

## 상태
| 상태   | 화면                   | 들어오는 조건 | 나가는 조건        |
|--------|------------------------|---------------|--------------------|
| 기본   | 라벨, 도움말           | 초기          | 포커스·오류·비활성 |
| 포커스 | 포인트색 테두리·링     | 칸 안 포커스  | 포커스 이동        |
| 오류   | 붉은 테두리, 오류 문구 | error에 문구  | error 비움         |
| 비활성 | 투명도 50%             | disabled=true | disabled=false     |

- 오류 상태는 도움말이 있어도 오류 문구가 같은 자리에 대신 보인다.

## 동작
- 입력: 이벤트가 아닌 문자열을 `onChange(value)`로 넘긴다.
- `value`를 넘기면 제어, 아니면 `defaultValue`(기본 빈 문자열)로 시작하는 내부 상태를 쓴다.
- `maxLength`와 `showCount`가 함께 있으면 `현재/최대` 글자 수를 오른쪽 아래에 보인다. `maxLength`를 넘는 입력은 브라우저가 막는다.
- 칸 안의 여백(`trailing` 주변)을 눌러도 입력창에 포커스가 간다.
- 라벨은 입력창과 연결되고, 도움말·오류·글자 수는 `aria-describedby`로 읽힌다. 오류 상태면 `aria-invalid`가 켜진다.
- 도움말·오류 문구는 바뀔 때 `aria-live="polite"`로 읽힌다.
- `type`, `placeholder`, `onBlur`, `autoComplete` 등 `input` 속성은 그대로 전달한다.

## 예외
- 검사 로직은 없다. 언제 무엇을 검사할지(입력 중, blur)는 쓰는 쪽에서 정하고 `error`로 넘긴다.
- 도움말·오류가 모두 없어도 한 줄 높이는 확보해 아래 요소가 움직이지 않는다.
- 비활성: 입력과 포커스가 모두 막힌다.
- `showCount`만 있고 `maxLength`가 없으면 글자 수를 보이지 않는다.
- 제어 모드에서 `value`를 갱신하지 않으면 입력이 화면에 반영되지 않는다.
- 붙여넣기로 길이를 넘기는 경우의 잘림 안내는 하지 않는다.

## 인수 조건
- Given 닉네임 "하", When 화면을 본다, Then 입력칸이 붉은 테두리이고 "2~12자로 입력해 주세요"가 보인다.
- Given 닉네임 최대 12자, When 12자를 입력한 뒤 한 글자를 더 입력한다, Then 입력되지 않고 글자 수는 12/12다.
- Given 데모의 이메일 칸에 "abc" 입력, When 칸을 벗어난다, Then 오류 문구가 보이고 벗어나기 전에는 보이지 않았다.
- Given 오류 상태, When 스크린리더로 읽는다, Then `aria-invalid`가 true이고 오류 문구가 설명으로 읽힌다.
- Given `disabled=true`, When 칸을 누르거나 Tab으로 이동한다, Then 입력창에 포커스가 가지 않는다.
- Given 입력칸 오른쪽 빈 여백, When 클릭한다, Then 입력창에 포커스가 간다.

## 측정
- `field_error_shown` { field_name, error_type }
- `field_completed` { field_name, length } : blur 시점. 입력값 자체는 남기지 않는다.
- `form_submit_blocked` { field_name, error_type }

## 범위 밖
- 값 검증 규칙, 서버 중복 확인, 검사 시점 결정.
- 여러 줄 입력, 비밀번호 보기 토글(`trailing`으로 쓰는 쪽에서 구성).
- 자동완성 목록, 입력 마스킹.
