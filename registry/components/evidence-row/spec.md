# 증거 목록 행 기능 명세
썸네일·위치·제목·요약을 한 줄로 묶은 목록 행.

## 목적
- 수집한 단서를 목록에서 훑고, 누르면 상세로 넘어가게 한다.
- 문서·사물 사진이 잘리지 않게 담는다. (출처: Murder Mystery Generator 추리 게임)

## 사용자 시나리오
1. 추리 게임 중 사용자가 수집한 단서 목록에서 위치와 제목, 두 줄 요약으로 단서를 구분한다.
2. 사용자가 행을 눌러 단서 상세(시트·모달)를 연다.
3. 사진이 없는 단서는 제목 첫 글자 타일로 구분한다.

## 상태
| 상태        | 화면               | 들어오는 조건  | 나가는 조건     |
|-------------|--------------------|----------------|-----------------|
| 기본        | 썸네일·제목·화살표 | 마운트         | 호버·포커스     |
| 호버        | 배경이 옅게 깔림   | 포인터가 행 위 | 포인터가 벗어남 |
| 이미지 없음 | 제목 첫 글자 타일  | `image`가 없음 | `image`가 생김  |

- `meta`와 `description`은 값이 있을 때만 그 줄이 나온다.

## 동작
- 행 전체가 하나의 `button`이다. 클릭·Enter·Space로 `onClick`을 호출한다.
- 제목과 위치는 한 줄에서 말줄임, 요약은 두 줄까지 보이고 넘으면 말줄임이다. 행 높이가 일정하다.
- 썸네일은 64px 정사각형 안에 `object-contain`으로 담는다. 영수증·쪽지처럼 글자가 있는 이미지도 잘리지 않는다.
- 썸네일은 지연 로드한다. 이미지는 장식이라 `alt=""`다.
- 위치 핀 아이콘과 오른쪽 화살표는 인라인 SVG이고 `aria-hidden`이다.

## 예외
- `title`이 빈 문자열: 타일에 `?`가 나온다. 제목 없는 항목은 쓰는 쪽에서 막는다.
- 이미지 로드 실패: 제목 첫 글자 타일로 바뀐다.
- 선택 상태, 읽음 표시, 새 단서 표시: 처리하지 않는다. 쓰는 쪽에서 처리한다.
- 비활성화(`disabled`) 상태: 지원하지 않는다.
- 상세를 여는 방식, 열린 뒤 포커스 이동: 쓰는 쪽에서 처리한다.
- 긴 제목·요약: 말줄임으로 자르고 전체는 상세에서 보여준다.

## 인수 조건
- Given `image`가 있는 행, When 렌더한다, Then 64px 정사각 썸네일 안에 이미지가 잘리지 않고 들어간다.
- Given `image`가 없고 제목이 "익명의 쪽지", When 렌더한다, Then "익" 글자 타일이 보인다.
- Given 요약이 세 줄 이상, When 렌더한다, Then 두 줄까지만 보이고 말줄임이 붙는다.
- Given 행에 포커스, When Enter 또는 Space, Then `onClick`이 한 번 호출된다.
- Given `meta="서재"`, When 렌더한다, Then 제목 위에 핀 아이콘과 "서재"가 작게 보인다.
- Given `meta`가 없음, When 렌더한다, Then 핀 아이콘도 나오지 않는다.

## 측정
- `evidence_opened` { evidence_id, has_image, position_in_list } : `onClick`에서 남긴다.
- `evidence_list_viewed` { item_count } : 목록 화면에 들어올 때 남긴다.

## 범위 밖
- 상세 시트·모달
- 목록 정렬·필터·검색
- 행 안의 보조 버튼(삭제, 즐겨찾기 등)
- 사진 중심 갤러리 배치
