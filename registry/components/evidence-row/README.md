# 증거 목록 행

썸네일·위치·제목·요약을 한 줄로 묶은 목록 행.

## Props
| 이름          | 타입         | 기본값 | 설명                     |
|---------------|--------------|--------|--------------------------|
| `title`       | `string`     | -      | 한 줄, 넘치면 말줄임     |
| `image`       | `string`     | -      | 없으면 제목 첫 글자 타일 |
| `meta`        | `string`     | -      | 위치 핀과 함께 위에 작게 |
| `description` | `string`     | -      | 두 줄까지                |
| `onClick`     | `() => void` | -      | 상세 열기                |

## 구현 메모
- 썸네일은 `object-contain`. 영수증·증서처럼 글자가 있는 문서 이미지가 잘리지 않게 한다.
- 제목·위치는 `truncate`, 요약은 `line-clamp-2`라 행 높이가 일정하다.
- 아이콘은 인라인 SVG라 아이콘 라이브러리가 필요 없다.
