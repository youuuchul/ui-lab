# 세그먼트 프로그레스 기능 명세
정해진 단계 수를 차례로 채우는 진행 표시.

## 목적
- 단계 수가 고정되고 자동으로 넘어가는 흐름(스토리·온보딩)에서 현재 단계와 남은 단계를 보여준다.
- 이 항목의 출처 프로젝트는 meta에 기록돼 있지 않다.

## 사용자 시나리오
1. 사용자가 4단계 안내를 보는 동안, 칸이 한 칸씩 차례로 차오르는 것으로 진행 정도를 안다.
2. 마지막 칸이 차면 다음 화면으로 넘어가거나 완료 표시가 나타난다.
3. 모션 줄이기를 켠 사용자는 칸이 서서히 차지 않고, 각 단계 시작 때 한 번에 찬다.

## 상태
| 상태 | 화면                           | 들어오는 조건             | 나가는 조건              |
|------|--------------------------------|---------------------------|--------------------------|
| 대기 | 모든 칸이 비어 있음            | 마운트 직후 첫 칸 시작 전 | 첫 칸 채움 시작          |
| 진행 | 앞선 칸은 가득, 현재 칸 차오름 | 이전 칸이 끝남            | 현재 칸이 가득 참        |
| 완료 | 모든 칸이 가득 참              | 마지막 칸이 끝남          | 다시 마운트 (`key` 변경) |

- 현재 단계 번호는 `aria-valuenow`(0~`segments`)로 노출한다.
- 한 칸이 차는 시간은 `duration`(기본 2000ms)이고, 선형으로 찬다.

## 동작
- 사용자 입력은 없다. 마운트되면 첫 칸부터 자동으로 시작해 한 칸씩 이어서 찬다.
- 칸이 끝나면 다음 칸이 바로 시작한다. 마지막 칸이 끝나면 `onComplete`를 한 번 호출한다.
- 채움은 `scaleX` 0 → 1을 Web Animations API로 처리한다. 왼쪽 기준으로 늘어난다.
- 모션 줄이기: 칸이 시작되는 즉시 가득 찬 상태가 되고, `duration`이 지나면 다음 칸으로 넘어간다.
- 다시 재생하려면 `key`를 바꿔 다시 마운트한다.
- `role="progressbar"`, `ariaLabel`(기본 "진행률"), `aria-valuemin=0`, `aria-valuemax=segments`를 노출한다.
- `onComplete`는 최신 함수를 ref로 참조한다. 렌더마다 새 함수를 넘겨도 진행 중인 칸이 다시 시작되지 않는다.

## 예외
- `segments`가 0: 칸이 없고 마운트 즉시 `onComplete`를 호출한다.
- `segments`나 `duration`이 중간에 바뀜: 현재 칸의 애니메이션을 취소하고 새 값으로 현재 칸을 다시 시작한다. 완료 상태에서 바뀌면 `onComplete`가 다시 호출될 수 있다. 쓰는 쪽에서 값을 고정한다.
- 일시정지, 이전·다음 단계로 이동: 지원하지 않는다. 쓰는 쪽에서 `key`로 처리한다.
- 현재 단계 표시: 이 컴포넌트는 막대만 그린다. 쓰는 쪽에서 제목·이미지로 함께 보여준다.
- 끝을 알 수 없는 로딩: 쓰지 않는다. 스켈레톤이나 스피너를 쓴다.
- 단계 7개 초과: 칸이 얇아진다. 쓰는 쪽에서 숫자 진행으로 바꾼다.

## 인수 조건
- Given `segments=4`, `duration=1200`, When 마운트된다, Then 첫 칸이 1.2초 동안 선형으로 차고 이어서 두 번째 칸이 시작된다.
- Given 두 번째 칸 진행 중, When 화면을 본다, Then 첫 칸은 가득 차 있고 셋째·넷째 칸은 비어 있으며 `aria-valuenow`는 1이다.
- Given 마지막 칸이 끝남, When 완료된다, Then `onComplete`가 한 번 호출되고 `aria-valuenow`는 `segments`다.
- Given `onComplete`가 매 렌더마다 새 함수, When 진행 중 부모가 다시 렌더된다, Then 현재 칸의 채움이 다시 시작되지 않는다.
- Given 모션 줄이기 설정, When 칸이 시작된다, Then 그 칸이 즉시 가득 차고 `duration` 뒤 다음 칸으로 넘어간다.
- Given 완료된 상태, When 부모가 `key`를 바꾼다, Then 모든 칸이 비워지고 처음부터 다시 시작한다.

## 측정
- `progress_completed` { segments, duration } : `onComplete`에서 남긴다.
- `progress_abandoned` { reached_segment, segments } : 완료 전에 화면을 떠날 때 쓰는 쪽에서 `aria-valuenow` 기준으로 남긴다.

## 범위 밖
- 단계별 콘텐츠 전환
- 칸을 눌러 이동, 일시정지, 건너뛰기
- 불확정 로딩 표시
- 숫자 진행 표시(3/12)
