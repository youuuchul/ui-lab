# 세그먼트 프로그레스

스토리·온보딩처럼 정해진 개수의 단계를 차례로 채우는 진행 표시.

## Props
| 이름         | 타입         | 기본값     | 설명                      |
|--------------|--------------|------------|---------------------------|
| `segments`   | `number`     | -          | 칸 수                     |
| `duration`   | `number`     | `2000`     | 한 칸이 채워지는 시간(ms) |
| `onComplete` | `() => void` | -          | 마지막 칸이 채워지면 호출 |
| `ariaLabel`  | `string`     | `"진행률"` | 진행 막대의 접근성 이름   |
| `className`  | `string`     | `""`       | 바깥 컨테이너 클래스      |

## 구현 메모
- 채우기는 Web Animations API(`element.animate`)로 `scaleX`를 0→1로 바꾼다. width 전환과 달리 첫 칸이 마운트될 때도 애니메이션이 걸리고 레이아웃을 다시 계산하지 않는다.
- `prefers-reduced-motion`이면 채움 애니메이션 없이 칸이 시작될 때 가득 찬 상태로 바뀌고, `duration`마다 다음 칸으로 넘어간다.
- 다시 재생하려면 `key`를 바꿔 다시 마운트한다.
- `onComplete`는 ref에 담아 effect 의존성에서 뺐다. 쓰는 쪽이 매 렌더마다 새 함수를 넘겨도 진행 중인 칸이 다시 시작되지 않는다.
