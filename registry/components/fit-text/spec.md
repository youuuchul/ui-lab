# 폭 맞춤 타이포 기능 명세
큰 제목 줄을 컨테이너 폭에 꼭 맞추는 훅.

## 목적
- 포스터형 제목이 글꼴·글자 수와 상관없이 컨테이너 폭을 같은 비율로 채우게 한다.
- 창 크기가 바뀌어도 줄바꿈 없이 폭에 맞춘다. (출처: 포트폴리오 사이트 첫 화면)

## 사용자 시나리오
1. 방문자가 데스크톱에서 포트폴리오 첫 화면을 열면, 제목 줄들이 컨테이너 폭을 꽉 채운다.
2. 방문자가 창을 줄이거나 모바일로 보면, 제목이 같은 비율로 줄고 좁은 화면용 비율이 적용된다.
3. 웹폰트가 늦게 도착하면, 제목 크기가 한 번 다시 맞춰진다.

## 상태
| 상태      | 화면                       | 들어오는 조건                 | 나가는 조건        |
|-----------|----------------------------|-------------------------------|--------------------|
| 넓은 화면 | `data-fit` 비율 적용       | 화면 폭 720px 초과            | 화면 폭 720px 이하 |
| 좁은 화면 | `data-fit-m` 비율 우선     | 화면 폭 720px 이하            | 화면 폭 720px 초과 |
| 높이 제한 | 모든 줄이 같은 배율로 축소 | `data-fit-h`가 있고 높이 초과 | 높이 여유가 생김   |

- 좁은 화면에서 `data-fit-m`이 없으면 `data-fit`을 쓴다.
- 높이 제한은 줄 묶음 높이가 화면 높이 × `data-fit-h`를 넘을 때만 걸린다.

## 동작
- 훅 `useFit(dep?)`이 반환한 ref를 컨테이너에 붙이고, 맞출 줄에 `data-fit="비율"`을 단다. 1은 컨테이너 폭 전체다.
- 줄을 100px로 놓고 `scrollWidth`를 잰 뒤 `폰트 크기 = 100 × 컨테이너 폭 × 비율 / 측정 폭`으로 정한다.
- 다시 맞추는 시점
  - 첫 그리기 전(`useLayoutEffect`)
  - 컨테이너 크기 변화, 창 크기 변화
  - 웹폰트 로드 완료(`fonts.ready`, `loadingdone`)
  - `dep` 값 변화
- 사용자 입력(클릭·키보드)은 없다.

## 예외
- 컨테이너에 패딩이 있으면 폭이 패딩 포함으로 잡혀 줄이 넘친다. 쓰는 쪽에서 안쪽 래퍼에 ref를 붙인다.
- 줄이 `display: block`, `white-space: nowrap`이 아니면 측정이 틀린다. 쓰는 쪽에서 지정한다.
- 줄 폭이 0(숨김 요소 등): 그 줄은 건너뛴다.
- `data-fit` 값이 숫자가 아님: 처리하지 않는다. 쓰는 쪽에서 숫자로 준다.
- 서버 렌더: `useLayoutEffect` 경고 없이 건너뛴다. 첫 페인트 전 맞추므로 크기가 튀지 않는다.
- 내용이 바뀌는데 `dep`을 안 넘기는 경우: 다시 맞추지 않는다. 쓰는 쪽에서 `dep`을 넘긴다.
- 본문·버튼 글자에는 쓰지 않는다.

## 인수 조건
- Given 컨테이너 폭 320px, `data-fit="1"` 줄, When 렌더한다, Then 줄의 텍스트 폭이 약 320px이다.
- Given `data-fit="0.6"` 줄, When 렌더한다, Then 줄 폭이 컨테이너의 약 60%다.
- Given 컨테이너 폭이 320에서 192px로 바뀜, When 리사이즈된다, Then 각 줄의 폰트 크기가 비례해 줄어들고 줄바꿈은 없다.
- Given 화면 폭 700px, `data-fit-m="0.8"`, `data-fit="1"`, When 렌더한다, Then 0.8 비율을 쓴다.
- Given `data-fit-h="0.5"`이고 줄 묶음 높이가 화면 높이의 50%를 넘음, When 렌더한다, Then 모든 줄이 같은 배율로 줄어 비율 관계가 유지된다.
- Given 웹폰트가 늦게 로드됨, When 폰트가 도착한다, Then 폰트 크기를 다시 계산한다.

## 측정
- 이벤트 없음. 화면을 맞추는 훅이라 사용자 행동이 없다.
- 필요하면 `fit_overflow_detected` { container_width, line_width, viewport_width } : 쓰는 쪽에서 레이아웃 점검용으로 남긴다.

## 범위 밖
- 여러 줄 자동 줄바꿈(한 줄 전제)
- 최소·최대 글자 크기 제한
- 본문, 버튼, 폼 글자
- 글꼴 로딩 자체
