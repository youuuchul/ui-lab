# 폭 맞춤 타이포

큰 제목 줄을 컨테이너 폭에 꼭 맞추는 훅. 줄마다 폭 대비 비율을 주면 글꼴·글자 수와 상관없이 같은 폭을 차지한다.

## `useFit<T>(dep?)`
컨테이너에 반환된 ref를 붙이고, 맞출 줄에 data 속성을 단다.

| 속성 | 위치 | 설명 |
|---|---|---|
| `data-fit` | 줄 | 컨테이너 폭 대비 비율 (`1` = 꽉 채움) |
| `data-fit-m` | 줄 | 화면 폭 720px 이하에서 쓸 비율 (없으면 `data-fit`) |
| `data-fit-h` | 컨테이너 | 줄 묶음 높이 상한 = 화면 높이 × 이 비율. 넘으면 모든 줄을 같은 배율로 줄임 |

`dep`이 바뀌면 다시 맞춘다 (글자 내용이 바뀔 때).

## 구현 메모
- 기준 폭은 컨테이너의 `clientWidth`(패딩 포함)다. 패딩이 있는 박스에는 ref를 붙이지 말고 안쪽 요소에 붙인다.
- 줄을 `100px`로 놓고 `scrollWidth`를 재서 비례 계산한다. 줄은 `display: block` + `white-space: nowrap`이어야 정확하다.
- 웹폰트가 늦게 오면 폭이 달라지므로 `document.fonts.ready`와 `loadingdone`에서도 다시 맞춘다.
- `useLayoutEffect`로 첫 그리기 전에 맞춰 크기가 튀지 않는다. Next 서버 렌더에서는 경고 없이 건너뛴다(React 19).
