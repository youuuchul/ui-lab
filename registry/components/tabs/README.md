# 탭

같은 화면 안에서 관련 내용을 나눠 바꿔 보는 탭. 밑줄이 선택을 표시한다.

## Props
| 이름                     | 타입                                     | 기본값         | 설명                  |
|--------------------------|------------------------------------------|----------------|-----------------------|
| `items`                  | `{ value, label, content, disabled? }[]` | -              | 탭과 패널             |
| `value` / `defaultValue` | `string`                                 | - / 첫 활성 탭 | 제어 / 비제어         |
| `onChange`               | `(value: string) => void`                | -              |                       |
| `label`                  | `string`                                 | -              | 탭 목록의 접근성 이름 |
| `fitted`                 | `boolean`                                | `false`        | 탭을 같은 폭으로 나눔 |

## 접근성
- `tablist` / `tab` / `tabpanel` 구조. `aria-selected`, `aria-controls`, `aria-labelledby`로 서로 연결한다.
- 선택된 탭만 Tab으로 들어가고, ←→·Home·End로 옮기면 바로 선택된다(자동 활성). 비활성 탭은 건너뛴다.

## 구현 메모
- 밑줄은 탭마다 하나씩 두고 `scaleX` 0↔1로 바꾼다. 탭 위치를 재지 않아서 라벨 길이가 달라도, 서버 렌더에서도 어긋나지 않는다.
- 패널은 모두 렌더링하고 `hidden`으로 숨긴다. 다른 탭에 다녀와도 패널 안 상태가 유지된다.
