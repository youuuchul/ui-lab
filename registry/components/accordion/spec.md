# 아코디언 기능 명세
제목을 눌러 내용을 펼치고 접는 목록. 자주 묻는 질문처럼 훑어보고 골라 읽는 내용에 쓴다.

## 목적
- 질문·항목 제목만 먼저 보여주고, 필요한 내용만 열어 읽게 한다.

## 사용자 시나리오
1. 이용자가 "환불은 언제 되나요?"가 열린 FAQ에서 "영수증은 어디서 받나요?"를 누른다.
2. 열려 있던 항목은 접히고 새 항목이 펼쳐진다.
3. 키보드 사용자가 제목에 Tab으로 가서 Enter·Space로 펼친다.

## 상태
| 상태   | 화면                | 들어오는 조건          | 나가는 조건              |
|--------|---------------------|------------------------|--------------------------|
| 닫힘   | 제목만, 화살표 아래 | 초기·다시 누름         | 제목 누름                |
| 열림   | 내용, 화살표 위     | 제목 누름·defaultValue | 다시 누름·다른 항목 열림 |
| 포커스 | 바깥 링             | 키보드 포커스          | 포커스 이동              |

- `type="single"`은 열린 항목이 하나뿐이다. `multiple`은 여러 개가 동시에 열린다.

## 동작
- 제목 클릭·Enter·Space: 그 항목을 열거나 닫는다. 열린 항목을 다시 누르면 `single`에서도 닫힌다.
- `single`에서 다른 항목을 열면 이전 항목이 닫힌다.
- `onChange`는 열린 항목 값의 배열 전체를 넘긴다.
- `value`를 넘기면 제어, 아니면 `defaultValue`(기본 모두 닫힘)로 시작한다.
- 펼침은 높이와 투명도가 0.3초(닫힘은 0.2초) 동안 바뀐다. 화살표도 같이 돈다.
- 닫힌 패널은 `inert`라 Tab 이동과 스크린리더에서 빠진다.
- 제목은 `h3` 안의 버튼이고 `aria-expanded`가 열림 상태를 따른다.
- 동작 줄이기에서는 전환 없이 바로 열고 닫힌다.

## 예외
- 모든 항목이 닫힌 상태는 정상이다.
- `single`인데 `defaultValue`에 여러 값을 넘기면 모두 열린다. 쓰는 쪽에서 한 개만 넘긴다.
- 제목·내용에 `ReactNode`를 받으므로 내용 길이나 중첩 아코디언은 막지 않는다. 중첩은 쓰지 않는다.
- 제어 모드에서 `value`를 갱신하지 않으면 열림 상태가 바뀌지 않는다.
- 항목 값(`value`)이 중복되면 동작을 보장하지 않는다. 쓰는 쪽에서 유일하게 둔다.

## 인수 조건
- Given "환불" 항목이 열린 `single`, When "영수증" 제목을 클릭한다, Then "환불"이 닫히고 "영수증"이 열리며 `onChange(["receipt"])`가 호출된다.
- Given "환불" 항목이 열림, When 같은 제목을 클릭한다, Then 항목이 닫히고 `onChange([])`가 호출된다.
- Given `type="multiple"`, When 두 제목을 차례로 클릭한다, Then 두 내용이 모두 열려 있다.
- Given 닫힌 항목, When Tab으로 이동한다, Then 제목에는 포커스가 가고 내용 안 링크·버튼에는 가지 않는다.
- Given 제목에 포커스, When Space를 누른다, Then 열리고 `aria-expanded`가 true가 된다.
- Given 동작 줄이기 설정, When 항목을 연다, Then 높이 전환 없이 바로 열린다.

## 측정
- `accordion_item_toggled` { accordion_id, item_value, expanded, position }
- FAQ라면 `faq_item_opened` { item_value }로 어떤 질문이 읽히는지 남긴다.

## 범위 밖
- 주소(URL) 해시로 항목 열기, 외부에서 스크롤해 열기.
- 항목 내용 비동기 로딩.
- 중첩 아코디언, 항목 비활성.
- 모두 펼치기·모두 접기 버튼.
