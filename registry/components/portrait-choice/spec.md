# 인물 선택 목록 기능 명세
인물 사진과 이름으로 한 명을 고르는 단일 선택 목록.

## 목적
- 투표·지목처럼 사람을 고르는 질문에서, 얼굴과 이름을 함께 보고 한 명을 고르게 한다.
- 선택 상태를 테두리와 배경색 두 가지로 보여준다. (출처: Murder Mystery Generator 범인 지목)

## 사용자 시나리오
1. 추리 게임 마지막에 사용자가 "범인이라 생각하는 사람은?" 질문 아래 인물 사진을 보고 한 명을 누른다.
2. 키보드 사용자가 방향키로 후보를 옮기며 선택한다.
3. 제출 중에는 선택이 잠겨 바꿀 수 없다.

## 상태
| 상태   | 화면                           | 들어오는 조건              | 나가는 조건     |
|--------|--------------------------------|----------------------------|-----------------|
| 미선택 | 모든 항목이 회색 배경          | `value`가 어느 id와도 다름 | 항목 선택       |
| 선택됨 | 강조 테두리와 옅은 배경        | `value`가 항목 id와 같음   | 다른 항목 선택  |
| 호버   | 배경이 조금 진해짐             | 포인터가 미선택 항목 위    | 포인터가 벗어남 |
| 잠김   | 모든 항목이 흐림, 누를 수 없음 | `disabled`                 | `disabled` 해제 |

- 이미지가 없는 항목은 이름만 있는 낮은 행으로 그려진다.

## 동작
- 클릭·탭: 항목을 누르면 `onChange(id)`를 호출한다. 이미 선택된 항목을 다시 눌러도 호출되고 해제되지 않는다.
- 방향키: 아래·오른쪽은 다음, 위·왼쪽은 이전 항목으로 옮기며 즉시 선택한다. 처음과 끝에서 반대편으로 돈다.
- Tab: 선택된 항목이 하나의 탭 정지점이다. 선택이 없으면 첫 항목이다.
- 누르면 `scale(0.96)`으로 눌린다. 포커스 링이 보인다.
- 강조색은 `--color-accent`를 감싸는 요소에서 바꾸면 따라간다.
- `role="radiogroup"`과 `label`, 항목마다 `role="radio"`와 `aria-checked`를 노출한다.
- 사진은 3:4 세로 비율로 잘라 보이고, 지연 로드한다. 사진은 장식이라 `alt=""`이고 이름이 접근성 이름이다.

## 예외
- `value`가 `""`이거나 없는 id: 미선택으로 본다.
- `options`가 비어 있음: 빈 그룹만 그려지고 방향키는 무시한다.
- `disabled`: 클릭과 방향키를 모두 무시한다.
- 이미지 로드 실패: 이름 첫 글자로 바뀐다.
- 질문 문구 표시: 처리하지 않는다. `label`은 스크린리더용이라 화면에는 쓰는 쪽에서 따로 보여준다.
- 선택 해제, 다중 선택: 지원하지 않는다.
- 선택 후 제출 확인 단계: 쓰는 쪽에서 처리한다.

## 인수 조건
- Given 후보 3명, 미선택, When 두 번째 항목을 누른다, Then `onChange("b")`가 호출되고 `value="b"`로 바꾸면 그 항목에 테두리와 옅은 배경이 보인다.
- Given 세 번째 항목이 선택되고 포커스, When 아래 방향키를 누른다, Then 첫 항목이 선택되고 포커스가 옮겨간다.
- Given 첫 항목에 포커스, When 위 방향키를 누른다, Then 마지막 항목이 선택된다.
- Given 선택이 없음, When Tab으로 그룹에 들어온다, Then 첫 항목에 포커스가 간다.
- Given `disabled`, When 항목을 누르거나 방향키를 누른다, Then `onChange`가 호출되지 않는다.
- Given 선택된 항목, When 접근성 트리를 본다, Then 해당 항목만 `aria-checked="true"`다.

## 측정
- `suspect_selected` { option_id, previous_option_id, option_count } : `onChange`에서 남긴다. 용어는 쓰는 쪽 질문에 맞춘다.
- `choice_submitted` { option_id, changed_count, time_to_submit } : 제출할 때 남기고, `changed_count`는 선택을 바꾼 횟수.

## 범위 밖
- 질문 제목 표시
- 제출 버튼과 제출 처리
- 다중 선택, 선택 해제
- 사진 없는 일반 옵션 목록 (세그먼트 컨트롤·라디오를 쓴다)
