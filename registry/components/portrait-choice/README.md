# 인물 선택 목록

인물 사진과 이름으로 한 명을 고르는 단일 선택 목록.

## Props
| 이름       | 타입                     | 기본값  | 설명                                                 |
|------------|--------------------------|---------|------------------------------------------------------|
| `options`  | `{ id, name, image? }[]` | -       | 이미지는 3:4 세로 비율                               |
| `value`    | `string`                 | -       | 선택한 id. 없으면 `""`                               |
| `onChange` | `(id: string) => void`   | -       |                                                      |
| `label`    | `string`                 | -       | 묶음 이름. 화면에는 쓰는 쪽이 질문으로 따로 보여준다 |
| `disabled` | `boolean`                | `false` | 제출 중 잠금                                         |

## 구현 메모
- `role="radiogroup"` / `role="radio"` + `aria-checked`로 단일 선택임을 알린다.
- 선택은 `ring-inset` 테두리와 강조색 10% 배경. 링이 안쪽에 그려져 목록 간격이 흔들리지 않는다.
- 누를 때 `scale(0.96)`으로 눌림을 준다.
- 강조색은 `--color-accent`를 감싸는 요소에서 바꾸면 따라간다.
