# 크로스페이드 이미지 스택 기능 명세
표정처럼 자주 바뀌는 이미지를 깜빡임 없이 바꾸는 겹침 스택.

## 목적
- 캐릭터 표정처럼 같은 틀에서 이미지만 바뀌는 곳에서, 전환 때 로딩 깜빡임이 없게 한다.
- 모든 이미지를 처음에 받아 두어 바꿀 때 지연이 없다. (출처: HeartTable AI 캐릭터 표정)

## 사용자 시나리오
1. 캐릭터와 대화하는 사용자가 응답마다 바뀌는 표정을 끊김 없이 본다.
2. 알 수 없는 표정 키가 오면, 사용자는 기본 표정이 유지되는 것을 본다.

## 상태
| 상태      | 화면                 | 들어오는 조건                 | 나가는 조건               |
|-----------|----------------------|-------------------------------|---------------------------|
| 지정 표시 | `activeKey` 이미지   | `activeKey`가 `images`에 있음 | `activeKey` 변경          |
| 대체 표시 | `fallbackKey` 이미지 | `activeKey`가 `images`에 없음 | 유효한 `activeKey`        |
| 표시 없음 | 빈 틀                | 두 키 모두 없음               | 유효한 키가 생김          |
| 로드 실패 | 해당 이미지만 숨김   | 이미지 `onError`              | 없음 (다시 마운트 전까지) |

- 전환은 불투명도 300ms 크로스페이드다. 이전 이미지가 사라지는 동안 새 이미지가 나타난다.

## 동작
- 사용자 입력은 없다. `activeKey` 변경이 유일한 입력이다.
- 모든 이미지를 겹쳐 마운트하고 불투명도만 바꾼다. 바꿀 때 다시 받거나 디코드하지 않는다.
- 같은 URL이 여러 키에 걸려 있으면 한 번만 마운트한다.
- 보이는 이미지에만 `alt`를 주고 나머지는 `aria-hidden`과 빈 `alt`다.
- 이미지는 `object-cover`, 위쪽 기준으로 틀을 채우고 흰색 10% 외곽선이 있다.

## 예외
- `activeKey`가 없는 키: `fallbackKey`로 보여준다. `fallbackKey`도 없으면 아무것도 보이지 않는다.
- 이미지 로드 실패: 그 이미지만 `display: none`으로 숨긴다. 깨진 아이콘이 보이지 않는다. 대체 이미지로 바꾸지는 않는다.
- 빈 문자열 URL: 목록에서 제외한다.
- 이미지 크기가 서로 다름: 처리하지 않는다. 쓰는 쪽에서 같은 크기로 맞춘다.
- 이미지 수가 많을 때의 초기 로드 부담: 쓰는 쪽에서 4~6장 안으로 묶는다.
- `prefers-reduced-motion`: 전환 없이 바로 바뀐다.
- 틀의 크기와 비율: `className`으로 쓰는 쪽에서 지정한다.

## 인수 조건
- Given 키 4개 중 `smile`이 활성, When `activeKey`를 `shy`로 바꾼다, Then 300ms 동안 크로스페이드로 바뀌고 새 네트워크 요청이 생기지 않는다.
- Given `images`에 없는 `activeKey="angry"`, `fallbackKey="default"`, When 렌더한다, Then `default` 이미지가 보인다.
- Given 두 키가 같은 URL을 가리킴, When 렌더한다, Then 해당 `img`는 하나만 존재한다.
- Given 한 이미지의 로드가 실패함, When 렌더한다, Then 그 이미지만 숨겨지고 깨진 아이콘이 보이지 않는다.
- Given 활성 이미지, When 접근성 트리를 본다, Then 활성 이미지만 `alt`를 가지고 나머지는 `aria-hidden`이다.

## 측정
- `expression_changed` { from_key, to_key, used_fallback } : `activeKey` 변경 시 쓰는 쪽에서 남긴다.
- `image_load_failed` { key } : 이미지 실패를 알아야 하면 쓰는 쪽에서 사전 로드로 확인한다. 컴포넌트에 콜백은 없다.

## 범위 밖
- 이미지 사전 로드·캐시 전략
- 키 결정 규칙(감정 → 표정 매핑)
- 슬라이드 이동, 확대, 갤러리 탐색
- 수십 장 규모의 이미지 관리
