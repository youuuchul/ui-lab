# 흐려지는 채팅 말풍선

배경 위에 대화를 띄우는 말풍선. 최신 왕복만 선명하고 위로 밀린 메시지는 흐려진다. 누르고 있으면 다시 선명해진다.

## Props
| 이름 | 타입 | 기본값 | 설명 |
|---|---|---|---|
| `role` | `"user" \| "assistant" \| "system"` | - | 오른쪽 / 왼쪽 / 가운데 알림 |
| `content` | `string` | - | `*지문*` 구간은 지문으로 따로 렌더링 |
| `distanceFromLatest` | `number` | `0` | 최신 메시지로부터의 거리. 0·1은 불투명, 2부터 0.42 → 0.22 → 0.12 → 0.06 |
| `forceReadable` | `boolean` | `false` | 과거 대화를 스크롤해 읽는 중이면 흐림을 끔 |

## 구현 메모
- `narration.ts`의 `parseNarration`이 `*...*`를 지문 구간으로 나눈다. 상대 메시지는 스트리밍 중 닫히지 않은 `*`도 지문으로 본다(`allowOpenNarration`). 내 메시지는 짝이 맞을 때만 지문으로 본다.
- 상대 메시지는 대사와 지문이 따로 떨어진 블록이고, 지문은 그림자를 준 기울임체로 배경 위에서 읽히게 했다.
- 상대 메시지 내용이 비어 있으면(스트리밍 시작) `...`을 깜빡인다.
- 원본의 mouse·touch 이벤트 6개를 pointer 이벤트 4개로 합쳤다.
