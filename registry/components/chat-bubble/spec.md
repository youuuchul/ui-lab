# 흐려지는 채팅 말풍선 기능 명세
최신 왕복만 선명하고 위로 밀린 메시지는 흐려지는 말풍선.

## 목적
- 배경 이미지 위에 AI 캐릭터 대화를 띄울 때 장면을 가리지 않도록, 최신 왕복만 또렷하게 보인다.
- 대사와 `*지문*`을 나눠 그려 캐릭터 대화의 연출을 살린다. (출처: HeartTable AI)

## 사용자 시나리오
1. 캐릭터와 대화하는 사용자가 배경 장면을 보면서, 가장 최근 주고받은 두 메시지만 또렷하게 읽는다.
2. 사용자가 흐려진 지난 말풍선을 누르고 있는 동안, 그 메시지를 다시 읽는다.
3. 캐릭터 응답이 스트리밍으로 도착하는 동안, 사용자는 `...` 표시와 지문이 먼저 보이는 것을 확인한다.

## 상태
| 상태        | 화면                | 들어오는 조건                      | 나가는 조건                 |
|-------------|---------------------|------------------------------------|-----------------------------|
| 선명        | 불투명도 1          | `distanceFromLatest`가 0 또는 1    | 거리가 2 이상으로 커짐      |
| 흐림        | 불투명도 0.42 이하  | 거리 2 이상                        | 누름·포커스·`forceReadable` |
| 읽기 중     | 불투명도 1          | 누르는 중, 포커스, `forceReadable` | 손을 떼거나 포커스 벗어남   |
| 응답 대기   | `...` 말풍선 깜빡임 | assistant의 `content`가 빈 문자열  | 내용이 들어옴               |
| 시스템 알림 | 가운데 알약형 안내  | `role="system"`                    | `role` 변경                 |

- 거리 2~4는 순서대로 0.42, 0.22, 0.12이고 5 이상은 0.06이다.
- 최근(거리 0·1) 말풍선은 배경이 더 진하고 블러가 강하다. 그 밖은 옅다.

## 동작
- 포인터: 누르면 선명해지고, 떼거나 영역을 벗어나거나 취소되면 원래대로 돌아간다. 마우스·터치·펜 공통.
- 키보드: 말풍선이 `tabIndex=0`이라 Tab으로 포커스되면 선명해지고, 벗어나면 다시 흐려진다. 포커스 링이 보인다.
- 불투명도는 200ms 전환한다.
- 지문 처리: `*...*` 구간은 지문, 나머지는 대사로 나눈다.
  - assistant: 대사와 지문이 따로 떨어진 블록. 지문은 그림자 있는 기울임체. 닫히지 않은 `*`는 끝까지 지문으로 본다.
  - user: 한 말풍선 안에서 지문만 작은 기울임체. 닫히지 않은 `*`는 전체를 대사로 본다.
- 오른쪽(user)·왼쪽(assistant)·가운데(system)로 정렬한다.

## 예외
- 빈 `*  *`(공백뿐인 지문): 전체를 대사 하나로 본다.
- 내용이 공백뿐이거나 비어 있는 user 메시지: 빈 말풍선이 그려진다. 쓰는 쪽에서 빈 메시지를 막는다.
- 거리 계산, 정렬, 스크롤 위치: 쓰는 쪽에서 처리한다. 컴포넌트는 `distanceFromLatest`만 받는다.
- 긴 단어와 줄바꿈: `break-words`, `whitespace-pre-wrap`으로 처리한다.
- `prefers-reduced-motion`: `...` 깜빡임만 꺼지고 불투명도 전환은 유지된다.

## 인수 조건
- Given 메시지 5개가 거리 4~0으로 렌더됨, When 화면을 본다, Then 거리 0·1은 불투명도 1이고 거리 2는 0.42, 3은 0.22, 4는 0.12다.
- Given 거리 3으로 흐려진 assistant 말풍선, When 포인터를 누르고 있다 뗀다, Then 누르는 동안 불투명도 1이고 뗀 뒤 0.22로 돌아온다.
- Given 거리 3으로 흐려진 말풍선, When Tab으로 포커스한다, Then 불투명도 1이 되고 포커스 링이 보인다.
- Given `forceReadable`이 true, When 거리 5 메시지를 렌더한다, Then 불투명도 1이다.
- Given assistant `content`가 `"*고개를 돌린다* 왔어?"`, When 렌더한다, Then 지문과 대사가 별도 블록으로 나뉜다.
- Given assistant `content`가 빈 문자열, When 렌더한다, Then `...`가 깜빡이는 말풍선이 보인다.

## 측정
- `chat_message_reread` { role, distance_from_latest } : 흐려진 말풍선을 눌러 다시 읽을 때. 컴포넌트에 콜백이 없어 쓰는 쪽이 래퍼에서 남긴다.
- `chat_history_scroll` { reached_distance } : 과거 대화를 스크롤해 `forceReadable`을 켠 때.

## 범위 밖
- 메시지 목록·스크롤·자동 하단 고정
- 스트리밍 수신, 재시도, 전송 상태 표시
- 마크다운, 이미지, 링크 렌더
- 시간 표시, 읽음 표시, 복사·삭제 메뉴
