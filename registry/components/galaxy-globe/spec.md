# 은하수 글로브 기능 명세
기록 하나가 별빛 하나로 쌓이는 스노우글로브. 은하수 밀도층과 이름 있는 별빛, 내 별빛을 한 구 안에 겹쳐 그린다.

## 목적
- 쌓인 돌봄 기록의 양을 숫자 대신 별빛의 밀도로 보여준다.
- 내 별빛, 이름 있는 별빛, 익명 은하수를 한 구 안에서 구분해 보여준다. (출처: PetGlobe 반려동물 돌봄 기록)

## 사용자 시나리오
1. 반려동물 보호자가 홈에서 글로브를 보며, 쌓인 기록이 별빛으로 늘어난 것을 확인한다.
2. 보호자가 새 기록을 저장하면 별빛이 날아와 켜지는 연출을 본다.
3. 보호자가 다른 사람이 공개한 별빛에 마우스를 올리거나 탭해, 공개한 정보(이름·종·날짜)를 카드로 본다.

## 상태
| 상태      | 화면                    | 들어오는 조건             | 나가는 조건                 |
|-----------|-------------------------|---------------------------|-----------------------------|
| 흰빛      | 흰빛 별과 은하수        | `status="active"`         | `status`가 `rainbow`로 변경 |
| 무지갯빛  | 저채도 오팔빛이 섞임    | `status="rainbow"`        | `status`가 `active`로 변경  |
| 카드 표시 | 별빛 옆에 정보 카드     | 별빛에 호버·탭            | 다른 곳 호버, 바깥 탭       |
| 정지      | 렌더 루프 멈춤          | 화면 밖이거나 탭이 숨겨짐 | 화면 안으로 돌아옴          |
| 모션 줄임 | 반짝임·연출·기울기 꺼짐 | `prefers-reduced-motion`  | 설정 해제                   |

- 색 전환은 `statusAnimate`가 true일 때 물들듯 바뀐다. 첫 렌더에는 연출이 없다.
- 밀도층이 늘어날 때의 차오르는 연출은 `communityAnimate`가 true이고 첫 렌더가 아닐 때만 나온다.

## 동작
- 기울기: 기기 센서가 있으면 센서, 없으면 데스크톱 포인터 위치, 터치 기기는 아주 느린 자동 흔들림. 층마다 시차가 다르다.
- iOS 센서 권한은 글로브를 처음 누를 때 묻는다.
- 별빛 위치는 id에서 결정론적으로 정해진다. 순서가 바뀌거나 다시 마운트해도 같은 자리다.
- 내 별빛을 탭하면 `onTapLight(light)`를 호출한다. `interactive=false`여도 탭 판정은 계속된다.
- 호버·탭 카드: 이름 있는 별빛은 `renderCard` 내용(기본은 공개된 날짜·시간대·이름·종 한 줄). 카드는 회전하는 별빛을 따라가고 글로브 바깥을 누르면 닫힌다.
- 무지갯빛 별빛의 카드는 오팔 배경·테두리를 쓴다.
- 핸들(ref)
  - `gather()`: 흩어진 별빛이 모여든다.
  - `lightUp(light, fromClient?)`: 새 별빛이 날아와 켜진다. 끝나면 resolve한다.
  - `toClient(light | id)`: 별빛의 화면 좌표를 돌려준다.
  - `pointerOnLight()`: 마지막 탭이 별빛에 맞았는지 알려준다.
- `communityCount` 0~수십만: 밀도층 개수. `communityRainbowRatio`는 그중 무지갯빛 비율.
- `chrome="none"`은 유리 테두리·그림자 없이 하늘만 그린다. 그림 속 유리구 위에 얹을 때 쓴다.
- 영역은 `role="img"`와 `ariaLabel`(기본 "별빛 지구본")로 노출한다.

## 예외
- `lights`, `namedLights`가 비어 있음: 별빛 없이 하늘과 밀도층만 그린다.
- `backdropStars`: 마운트 때만 읽는다. 이후 바꿔도 반영되지 않는다.
- `lights`가 바뀜: 새 배열을 받아 즉시 반영한다. 연출이 필요하면 쓰는 쪽에서 `lightUp`을 먼저 호출한다.
- 새 기록이 아닌데 `lightUp`을 호출함: 처리하지 않는다. 쓰는 쪽에서 새 기록일 때만 호출한다.
- 센서 권한 거부: 오류를 무시하고 포인터·자동 흔들림으로 대체한다.
- 한 화면에 글로브를 여러 개 띄우는 비용: 처리하지 않는다. 쓰는 쪽에서 한 개로 제한한다.
- 정확한 개수 표시: 처리하지 않는다. 개수는 숫자로 따로 보여준다.
- 카드 내용에 개인정보가 들어가는지: 쓰는 쪽에서 공개 항목만 `NamedLight.info`에 넣는다.
- 별빛 접근성 대체 정보: 영역 이름만 제공한다. 개별 별빛 설명은 쓰는 쪽에서 처리한다.

## 인수 조건
- Given `lights` 18개, `communityCount` 24000, When 렌더한다, Then 내 별빛 18개가 가장 앞에 있고 뒤로 이름 있는 별빛, 은하수 밀도층이 겹쳐 보인다.
- Given 같은 id의 기록, When 글로브를 다시 마운트한다, Then 별빛이 같은 자리에 나타난다.
- Given 새 기록 저장, When `lightUp(light)`를 호출한다, Then 별빛이 날아와 켜지고 끝난 뒤 resolve된다.
- Given 데스크톱, When 이름 있는 별빛에 마우스를 올린다, Then 별빛 위에 카드가 뜨고 별빛이 돌아도 따라간다.
- Given 카드가 열림, When 글로브 바깥을 누른다, Then 카드가 닫힌다.
- Given `status`를 `active`에서 `rainbow`로 바꿈, `statusAnimate=true`, When 바뀐다, Then 흰빛에서 무지갯빛으로 물든다.
- Given 모션 줄이기 설정, When 렌더한다, Then 반짝임·연출·기울기가 꺼진다.
- Given 글로브가 화면 밖으로 스크롤됨, When 스크롤한다, Then 렌더 루프가 멈추고 돌아오면 다시 돈다.

## 측정
- `globe_light_added` { mood, total_lights } : `lightUp` 호출 직전에 남긴다.
- `globe_light_tapped` { light_id, mood } : `onTapLight`에서 남긴다.
- `globe_card_opened` { kind: "mine" | "named" } : `renderCard`가 처음 호출될 때 남긴다.
- `globe_gather_played` { source } : `gather` 호출 시점.

## 범위 밖
- 기록 저장·조회, 기분(mood) 판단
- 별빛 개수 표시 숫자, 범례
- 내 별빛 상세 화면 이동
- WebGL(three) 렌더러. 이 구현은 canvas2d만 쓴다.
- 보기 설정(내 별빛·남의 별빛 표시 토글)
