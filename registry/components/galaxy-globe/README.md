# 은하수 글로브

기록 하나가 별빛 하나로 쌓이는 스노우글로브. 은하수 밀도층과 이름 있는 별빛, 내 별빛을 한 구 안에 겹쳐 그린다.

## Props
| 이름                    | 타입                    | 기본값          | 설명                                                             |
|-------------------------|-------------------------|-----------------|------------------------------------------------------------------|
| `size`                  | `number`                | -               | 정사각형 한 변(px)                                               |
| `ariaLabel`             | `string`                | `"별빛 지구본"` | 캔버스 영역의 접근성 이름 (`role="img"`)                         |
| `lights`                | `Light[]`               | `[]`            | 가장 앞의 별빛. `lightFromMemory({ id, mood })`로 만든다         |
| `namedLights`           | `NamedLight[]`          | `[]`            | 이름 있는 별빛. `namedLightFromId({ id, status, info })`         |
| `communityCount`        | `number`                | `0`             | 은하수 밀도층 개수 (0 ~ 수십만)                                  |
| `communityRainbowRatio` | `number`                | `0.08`          | 밀도층 중 무지갯빛 비율                                          |
| `status`                | `"active" \| "rainbow"` | `"active"`      | 흰빛 / 무지갯빛                                                  |
| `chrome`                | `"full" \| "none"`      | `"full"`        | 유리 테두리·그림자를 그릴지. 그림 속 유리구 위에 얹을 때 `none`  |
| `backdropStars`         | `boolean`               | `true`          | 장식용 배경 별. 생성 때만 읽음                                   |
| `statusAnimate`         | `boolean`               | `false`         | status가 바뀔 때 색이 물드는 연출                                |
| `communityAnimate`      | `boolean`               | `false`         | 밀도층이 늘 때 차오르는 연출                                     |
| `interactive`           | `boolean`               | `true`          | 호버·탭 카드 표시                                                |
| `renderCard`            | `(target) => ReactNode` | 공개 정보 한 줄 | 별빛 카드 내용                                                   |
| `onTapLight`            | `(light) => void`       | -               | 내 별빛 탭                                                       |
| `ref`                   | `GalaxyGlobeRef`        | -               | `gather()`, `lightUp(light)`, `toClient(id)`, `pointerOnLight()` |

## 구현 메모
- 렌더러(`canvas2d.ts`)와 배치 규약(`shared.ts`)은 PetGlobe 원본을 그대로 옮겼다. 하늘, 은하수 띠, 밀도층, 배경 별, 이름 있는 별빛, 내 별빛, 유리 림을 층으로 쌓고, 기울기에 따라 층마다 다른 계수로 시차를 준다.
- 별빛 위치는 id 해시로 정해진다. 목록 순서가 바뀌거나 다시 마운트해도 같은 자리다.
- 기울기 입력은 기기 센서 → 데스크톱 포인터 → 아주 느린 자동 흔들림 순으로 고른다. iOS 센서 권한은 첫 탭에서 묻는다.
- 화면 밖(IntersectionObserver)이거나 탭이 숨겨지면 렌더 루프를 멈춘다. `prefers-reduced-motion`이면 반짝임·연출·기울기를 끈다.
- 카드는 회전하는 별빛을 매 프레임 따라가고, 글로브 바깥을 누르면 닫힌다.

### 원본 대비
| 유지                                                                                                              | 뺌                                                                                                                                                                 |
|-------------------------------------------------------------------------------------------------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| canvas2d 렌더러 전체(그림·연출·히트 판정), 배치 함수, 기울기 우선순위, 카드 추적·바깥 탭 닫기, 무지갯빛 카드 배경 | three(WebGL) 렌더러와 canvas2d → three 교차 페이드, 보기 설정(내 별빛/남의 별빛 표시 토글), 내 추억 카드(썸네일·기분 라벨), 카드 오팔 광택이 흐르는 CSS 애니메이션 |

원본은 마운트 즉시 canvas2d로 그리고 WebGL이 되면 three로 넘긴다. 그림 기준은 canvas2d 쪽이라 이것만으로 같은 모양이 나온다.
