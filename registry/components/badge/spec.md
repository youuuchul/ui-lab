# 배지 기능 명세
상태·분류·새 항목을 짧게 표시하는 라벨. 누를 수 없다.

## 목적
- 주문 상태나 새 항목처럼 짧은 분류를 목록 안에서 색과 글자로 구분하게 한다.

## 사용자 시나리오
1. 주문 목록에서 각 줄 오른쪽의 "배송 중"·"배송 완료"·"입금 대기"·"취소" 배지로 상태를 구분한다.
2. 가장 최근 주문 이름 옆의 "NEW"(solid) 배지로 새 항목임을 알아본다.

## 상태
| 상태    | 화면                    | 들어오는 조건    | 나가는 조건     |
|---------|-------------------------|------------------|-----------------|
| soft    | 옅은 바탕, 색 글자      | appearance=soft  | appearance 변경 |
| solid   | 채운 바탕, 흰/검은 글자 | appearance=solid | appearance 변경 |
| 점 표시 | 글자 앞 작은 원         | dot=true         | dot=false       |

- 톤은 neutral·accent·success·warning·danger 다섯 가지다.
- 크기는 sm(높이 20px)·md(높이 24px)다.
- 입력에 반응하는 상태(호버·포커스·눌림)는 없다.

## 동작
- 표시만 한다. 클릭·키보드·터치에 반응하지 않고 포커스도 받지 않는다.
- 글자는 줄바꿈하지 않고 줄어들지 않는다.
- `dot`은 장식이라 스크린리더에서 제외한다. 상태는 글자로 읽힌다.
- 상태가 없는 `span`이라 서버 컴포넌트에서도 쓴다.

## 예외
- 빈 `children`: 막지 않는다. 글자 없는 점만 남는 모양이 되므로 쓰는 쪽에서 글자를 넣는다.
- 긴 문장: 줄바꿈이 없어 영역을 넘칠 수 있다. 쓰는 쪽에서 한두 단어로 줄인다.
- 색만으로 의미를 전하지 않는다. 상태 이름을 글자로 쓰는 일은 쓰는 쪽에서 한다.
- 상태값과 톤의 대응(예: 취소는 danger)은 쓰는 쪽에서 정한다.

## 인수 조건
- Given `tone="success"`·기본 모양, When 렌더한다, Then 옅은 초록 바탕에 초록 글자로 보인다.
- Given `appearance="solid"`·`tone="accent"`, When 렌더한다, Then 포인트색 바탕에 흰 글자로 보인다.
- Given `dot`, When 렌더한다, Then 글자 앞에 현재 글자색의 작은 원이 보인다.
- Given 배지 위, When 클릭하거나 Tab을 누른다, Then 아무 동작도 없고 포커스도 가지 않는다.
- Given 스크린리더, When 배지를 읽는다, Then "배송 중" 같은 글자만 읽히고 점은 읽히지 않는다.
- Given 같은 상태가 여러 줄에 있음, When 목록을 본다, Then 같은 상태는 같은 톤이다.

## 측정
- 배지 자체의 이벤트는 없다. 배지가 가리키는 상태로 분석한다.
- `list_viewed` { list_type, status_counts } : 상태별 개수를 쓰는 쪽에서 남긴다.
