# 배지

상태·분류·새 항목을 짧게 표시하는 라벨. 누를 수 없다.

## Props
| 이름         | 타입                                                          | 기본값      | 설명                  |
|--------------|---------------------------------------------------------------|-------------|-----------------------|
| `children`   | `ReactNode`                                                   | -           | 한두 단어             |
| `tone`       | `"neutral" \| "accent" \| "success" \| "warning" \| "danger"` | `"neutral"` | 의미 색               |
| `appearance` | `"soft" \| "solid"`                                           | `"soft"`    | 옅은 바탕 / 채운 바탕 |
| `size`       | `"sm" \| "md"`                                                | `"md"`      | 높이 20 / 24px        |
| `dot`        | `boolean`                                                     | `false`     | 앞에 상태 점          |

## 접근성
- 텍스트를 그대로 읽는다. 색만으로 의미를 전하지 않도록 상태 이름을 글자로 쓴다.
- 상태 없는 `span`이라 서버 컴포넌트에서도 쓸 수 있다(`"use client"` 없음).
