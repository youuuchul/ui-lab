# 마스크 텍스트 등장 기능 명세
글자를 마스크 아래에서 올리고 위로 밀어내는 텍스트 전환.

## 목적
- 화면이 바뀔 때 제목·정보 패널이 줄 단위로 올라오고, 나갈 때 위로 밀려나게 해 시선을 이끈다.
- 부모 한 곳에서 상태를 내려 여러 줄의 순서를 맞춘다. (출처: 포트폴리오 사이트 화면 전환)

## 사용자 시나리오
1. 방문자가 포트폴리오에서 다음 장면으로 넘어가면, 새 제목이 단어 단위로 마스크 아래에서 올라온다.
2. 이전 장면의 글자는 위로 짧게 밀려나며 사라진다.
3. 모션 줄이기를 켠 방문자는 글자가 바로 보인다.

## 상태
| 상태   | 화면                      | 들어오는 조건            | 나가는 조건           |
|--------|---------------------------|--------------------------|-----------------------|
| hidden | 마스크 아래에 숨음        | 부모 `initial="hidden"`  | 부모가 `show`로 전환  |
| show   | 제자리로 올라와 보임      | 부모 `animate="show"`    | 부모가 `out`으로 전환 |
| out    | 위로 밀려나 사라짐        | 부모 `exit="out"`        | 언마운트              |
| 즉시   | 애니메이션 없이 바로 보임 | `prefers-reduced-motion` | 설정 해제             |

- 상태 이름은 motion `variants`의 `hidden` / `show` / `out`이다. 컴포넌트가 아니라 부모가 정한다.
- 등장은 0.7초, 퇴장은 0.28초다. 구분선(`Rule`)은 등장 0.9초다.

## 동작
- 사용자 입력은 없다. 전환은 부모의 상태 변화로만 일어난다.
- `riseGroup(stagger, delay?)`: 자식들의 순서 간격과 시작 지연을 정하는 부모 variants. 퇴장 간격은 0.01초로 고정이다.
- `Rise`: 한 덩어리(줄·버튼)를 통째로 올린다.
- `Words`: `text`를 공백 기준 단어로 나눠 각각 올린다. 줄바꿈된 제목도 줄마다 올라온 것처럼 보인다.
- `Rule`: 왼쪽에서 오른쪽으로 그어지는 1px 선. 색은 `currentColor`라 글자색 클래스로 정한다.
- 마스크는 위아래에 여유를 두고 같은 크기의 음수 여백으로 되돌려, 글자 윗부분과 받침이 잘리지 않고 레이아웃은 그대로다.
- 장면이 바뀌면 부모의 `key`를 바꿔 다시 마운트한다. `AnimatePresence mode="wait"`로 이전 장면의 퇴장이 끝난 뒤 새 장면이 시작한다.

## 예외
- 부모가 `hidden/show/out` variants를 내려주지 않음: 상태를 못 받아 애니메이션이 없다. 쓰는 쪽에서 부모에 `motion` 컴포넌트와 variants를 둔다.
- `Words`의 `text`가 연속 공백이나 빈 문자열: 빈 단어 마스크가 생긴다. 쓰는 쪽에서 정리한 문자열을 넘긴다.
- 모션 줄이기: `variants`를 빼서 애니메이션 없이 바로 보인다. `riseGroup`의 간격은 자식에 적용되지 않는다.
- 같은 화면에 묶음 여러 개를 동시에 올림: 처리하지 않는다. 쓰는 쪽에서 한 묶음으로 제한한다.
- 긴 본문 문단: 읽기 전에 기다리게 되므로 쓰는 쪽에서 쓰지 않는다.
- 의존성: `motion`이 필요하다.

## 인수 조건
- Given 부모가 `riseGroup(0.04)`로 `hidden → show`, When 마운트된다, Then 자식들이 0.04초 간격으로 순서대로 마스크 아래에서 올라온다.
- Given `Words text="작은 조각이 모여"`, When 등장한다, Then 단어 4개가 각각 올라온다.
- Given 보이는 장면, When 부모 `key`가 바뀐다, Then 이전 글자가 0.28초에 위로 빠지고, 이후 새 글자가 올라온다.
- Given `Rule`, When `show`가 된다, Then 선이 왼쪽에서 오른쪽으로 0.9초에 그어진다.
- Given 모션 줄이기 설정, When 마운트된다, Then 글자가 애니메이션 없이 바로 보인다.
- Given 한글 제목의 받침이 있는 글자, When 마스크 안에 있을 때, Then 받침과 윗부분이 잘리지 않는다.

## 측정
- `scene_changed` { from_scene, to_scene, trigger } : 장면 전환 시 쓰는 쪽에서 남긴다. 컴포넌트에는 콜백이 없다.

## 범위 밖
- 장면 전환 타이밍과 자동 넘김
- 스크롤 진입 감지(보이면 재생)
- 글자 단위(자모) 분할 애니메이션
- 본문 문단 전체 전환
