# 스켈레톤

내용이 오기 전 자리를 미리 잡아 두는 회색 틀. 로딩이 끝나도 화면이 튀지 않는다.

## Props
| 이름        | 타입                           | 기본값   | 설명                                             |
|-------------|--------------------------------|----------|--------------------------------------------------|
| `shape`     | `"rect" \| "circle" \| "text"` | `"rect"` | 상자 / 원 / 글줄                                 |
| `lines`     | `number`                       | `1`      | `text`일 때 줄 수. 여러 줄이면 마지막 줄을 60%로 |
| `className` | `string`                       | `""`     | 크기는 여기서 (`h-10 w-10` 등)                   |

## 접근성
- 스켈레톤 자체는 `aria-hidden`. 로딩 상태는 감싸는 영역에 `aria-busy={loading}`으로 알린다.
- `prefers-reduced-motion`이면 깜빡이지 않는다.

## 구현 메모
- 상태가 없어 `"use client"` 없이 서버 컴포넌트에서도 쓴다.
