# 채팅 입력창 기능 명세
추천 답변, 감싸기 버튼, 자동 높이를 갖춘 채팅 입력창.

## 목적
- 첫마디를 막막해하는 사용자가 추천 답변을 골라 고쳐 보낼 수 있게 한다.
- 한글 IME와 터치 기기에서 Enter 처리가 깨지지 않게 한다. (출처: HeartTable AI 캐릭터 대화)

## 사용자 시나리오
1. 첫 대화를 시작하는 사용자가 입력 없이 기다리면, 추천 버튼이 강조되어 눌러 볼 수 있다.
2. 사용자가 추천 하나를 눌러 입력창에 채우고, 내용을 고친 뒤 보낸다.
3. 사용자가 행동 묘사를 넣으려고 감싸기 버튼을 눌러 `*행동*`을 입력한다.

## 상태
| 상태      | 화면                  | 들어오는 조건                    | 나가는 조건                       |
|-----------|-----------------------|----------------------------------|-----------------------------------|
| 기본      | 입력창, 보내기 비활성 | 마운트, 전송 직후                | 글자 입력                         |
| 입력 중   | 보내기 활성           | 공백 제외 글자 있음              | 입력을 비움, 전송                 |
| 추천 강조 | `?` 버튼 맥박·링      | 빈 입력으로 `hintDelayMs` 경과   | 버튼 누름, 입력, 포커스 이탈      |
| 추천 열림 | 입력창 위 추천 패널   | `?` 버튼 누름                    | 추천 선택, 바깥 누름, 버튼 재누름 |
| 추천 로딩 | 패널에 `loadingLabel` | 패널 열림 + `suggestionsLoading` | 로딩 해제                         |
| 비활성    | 입력·버튼 모두 흐림   | `disabled`                       | `disabled` 해제                   |

- `suggestions`가 없으면(`undefined`) `?` 버튼과 강조 타이머가 없다. 빈 배열이면 버튼은 보이고 패널은 비어 있다.
- 강조 타이머는 `disabled` 해제 시점과 전송 직후에 다시 시작한다.

## 동작
- Enter: 포인터가 fine인 기기(데스크톱)는 전송, Shift+Enter는 줄바꿈. 터치 기기는 Enter가 줄바꿈이다.
- IME 조합 중 Enter(`isComposing`)는 조합 확정용이라 전송하지 않는다.
- 보내기 버튼 또는 폼 제출: 앞뒤 공백을 뺀 내용으로 `onSend`를 호출하고 입력을 비운다.
- 추천 선택: `onSuggestionUsed(추천, index)` 호출 → 입력창에 채우고 커서를 끝에 둔다. 바로 보내지 않는다.
- 감싸기(`wrap`): 선택한 글자가 있으면 `marker`로 감싸고 커서를 뒤에 둔다. 없으면 `marker + placeholder + marker`를 넣고 placeholder를 선택해 둔다.
- 자동 높이: 입력에 맞춰 늘고 `maxHeight`(기본 120px)에서 멈춰 스크롤한다.
- 추천 패널은 입력창 바깥을 누르면 닫힌다.
- 터치 대상: 둥근 버튼은 40×40px, 누르면 `scale(0.96)`.

## 예외
- 공백뿐인 입력: 보내기가 비활성이고 Enter도 전송하지 않는다.
- `disabled` 중 전송·감싸기: 무시한다. 입력 중이던 글자는 그대로 둔다.
- 추천 열림 중 `disabled`가 켜지면 패널을 닫고 강조 타이머도 끈다.
- 추천 로딩 실패, 재시도, 추천 개수 제한: 쓰는 쪽에서 처리한다.
- 중복 전송: 전송 즉시 입력을 비우므로 같은 내용은 두 번 나가지 않는다. 서버 중복 방지는 쓰는 쪽에서 처리한다.
- `prefers-reduced-motion`: 강조 맥박과 버튼 전환이 꺼진다.

## 인수 조건
- Given 데스크톱, 입력에 "안녕", When Enter, Then `onSend("안녕")`이 호출되고 입력이 비워진다.
- Given 데스크톱, When Shift+Enter, Then 전송 없이 줄이 바뀐다.
- Given 한글을 조합 중, When Enter, Then 전송되지 않고 조합만 확정된다.
- Given 터치 기기, When Enter, Then 줄바꿈만 된다. 전송은 보내기 버튼으로 한다.
- Given 입력창이 비어 있고 `hintDelayMs`가 3000, When 3초가 지난다, Then `?` 버튼이 강조된다. 글자를 입력하면 강조가 사라진다.
- Given 추천 패널 열림, When 추천 하나를 누른다, Then 입력창에 그 문구가 채워지고 패널이 닫히며 `onSend`는 호출되지 않는다.
- Given `wrap.marker`가 `*`, 선택 없음, When 감싸기 버튼을 누른다, Then `*행동*`이 들어가고 "행동"이 선택된다.

## 측정
- `chat_suggestion_opened` { suggestion_count } : 추천 패널을 열 때. 쓰는 쪽에서 `?` 버튼 래핑 또는 상태로 남긴다.
- `chat_suggestion_used` { index, edited_before_send } : `onSuggestionUsed`에서 남기고, `edited_before_send`는 전송 시 비교한다.
- `message_sent` { order, length, has_wrap } : `onSend`에서 남긴다. 첫 메시지 전송률 계산에 `order = 1`을 쓴다.
