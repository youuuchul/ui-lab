# 퍼널 히트맵 표 기능 명세
세그먼트별로 첫 단계 대비 단계 도달률을 숫자와 명도로 비교하는 퍼널 표.

## 목적
- 퍼널이 "어느 집단에서" 막히는지 한 표로 비교한다. (PlaceWave 저장소/docs/metrics.md C18 세그먼트별 퍼널)
- 단계마다 값 범위가 달라도 열 안에서 높고 낮음이 보이게 한다.

## 사용자 시나리오
1. 분석가가 전체 행과 회원·비회원 행을 비교해 비회원이 로그인·가입 단계에서 2.5%로 떨어지는 것을 찾는다.
2. 마케터가 유료·비유료 행을 비교해 유료 유입은 상세 도달이 높지만 결제 도달이 낮은 것을 본다.

## 상태
| 상태    | 화면                            | 들어오는 조건  | 나가는 조건 |
|---------|---------------------------------|----------------|-------------|
| 기본    | 행마다 첫 단계 수 + 단계별 % 칸 | 마운트         | -           |
| 같은 값 | 그 열의 모든 칸이 중간 명도     | 열 최소 = 최대 | 값 변경     |

## 동작
- 칸 값 = 첫 단계 대비 도달률 r(k) = n(k) ÷ n(첫 단계). (metrics.md C16·C18)
- 칸 명도는 열 안 최소~최대를 10~70% 강조색으로 선형 배치한다. (PlaceWave 저장소/docs/dashboard.md §3a "색은 열 안 최소~최대 명도")
- 같은 축(group)의 첫 행에만 축 이름을 보인다.
- 조작은 없다. 표 구조(`caption`, `th scope`)로 스크린리더가 행·열 머리를 함께 읽는다.

## 예외
- 첫 단계가 0인 세그먼트: 쓰는 쪽에서 행을 뺀다(원본은 랜딩 0인 오디언스를 비활성으로 둔다).
- 좁은 화면: 표만 가로 스크롤(최소 30rem).
- 단계 수 계산(같은 날 누적 조건, 기간 고유 사람): 쓰는 쪽에서 처리한다.

## 인수 조건
- Given 회원 행 결제 46.5%가 열 최대, When 렌더한다, Then 그 칸이 열에서 가장 진하다.
- Given 비회원 행 결제 0.1%가 열 최소, When 렌더한다, Then 가장 옅지만 숫자는 읽힌다.
- Given 채널 축 두 행, When 렌더한다, Then "채널"은 첫 행에만 보인다.

## 측정
- 조작이 없어 부품 이벤트는 없다. 세그먼트 축 선택을 붙이면 `funnel_segment_axis_changed` { axis } (가정)를 남긴다.

## 범위 밖
- 세그먼트 축 선택·필터
- 단계 사이 전환율(직전 단계 대비) 표시
- 칸 클릭 드릴다운
