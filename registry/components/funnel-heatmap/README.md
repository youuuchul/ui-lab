# 퍼널 히트맵 표

세그먼트별로 첫 단계 대비 단계 도달률을 숫자와 명도로 비교하는 퍼널 표.

데모 수치는 PlaceWave의 가상 플랫폼 데이터(시나리오로 생성한 합성 데이터)이며 실제 서비스 데이터가 아니다.

## Props
| 이름        | 타입                                         | 기본값   | 설명                                                        |
|-------------|----------------------------------------------|----------|-------------------------------------------------------------|
| `title`     | `string`                                     | -        | 표 제목(caption)                                            |
| `steps`     | `string[]`                                   | -        | 첫 단계 뒤 단계 이름                                        |
| `rows`      | `{ group?; label; base; rates: number[] }[]` | -        | `base`는 첫 단계 사람 수, `rates`는 첫 단계 대비 도달률 0~1 |
| `baseLabel` | `string`                                     | `"랜딩"` | 첫 단계 열 이름                                             |

## 구현 메모
- 칸 명도는 열마다 최소~최대를 10~70% 강조색으로 펼친다. 단계마다 값 범위가 크게 달라 표 전체 기준이면 뒤 단계가 모두 옅어진다.
- 칸 안에 항상 % 숫자가 있어 색 없이도 읽힌다. caption에 명도의 뜻을 적는다.
- 같은 `group`의 첫 행에만 축 이름을 보이고, 나머지는 자리만 차지하게 숨긴다.
- 좁은 화면에서는 표만 가로로 스크롤한다(최소 30rem).
