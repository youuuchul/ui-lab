# KPI 스코어보드 기능 명세
핵심 지표를 값·직전 기간 대비 증감·분모 한 줄로 한 줄에 늘어놓는 스코어보드.

## 목적
- 화면을 연 사람이 "이번 기간이 직전보다 나아졌나"를 칸 몇 개로 바로 읽게 한다. (출처: PlaceWave 대시보드 각 탭 상단)
- 설명 문장 대신 라벨·단위·분모 한 줄로 값을 해석하게 한다. (PlaceWave 저장소/docs/dashboard.md §1 원칙 3)

## 사용자 시나리오
1. 운영자가 개요 탭을 열어 첫 칸(북극성 지표 결제)의 값과 ▲·▼를 먼저 본다.
2. 검색 담당자가 결과 0건 비율 ▲ 1.8%p가 빨간색인 것을 보고, 낮을수록 좋은 지표가 나빠졌음을 안다.
3. 분석가가 보조 줄 "검색 9,713건 중"으로 비율의 분모 규모를 확인한다.

## 상태
| 상태      | 화면                      | 들어오는 조건                      | 나가는 조건    |
|-----------|---------------------------|------------------------------------|----------------|
| 좋아짐    | 실제 방향 화살표 + 초록   | 증감 방향 = `good`                 | 값 변경        |
| 나빠짐    | 실제 방향 화살표 + 빨강   | 증감 방향 ≠ `good`                 | 값 변경        |
| 변화 없음 | 화살표 없이 회색 `0.0%p`  | 소수 첫째 자리 반올림 0            | 값 변경        |
| 계산 불가 | 회색 `—`                  | `delta.value`가 null (전기 0 등)   | 값이 생김      |
| 전기 없음 | 증감 줄 빈칸(높이는 유지) | `delta` 생략 (직전 기간이 범위 밖) | `delta`가 생김 |

- `good` 기본값은 `"up"`.

## 동작
- 입력은 표시용으로 만든 문자열 값과 숫자 증감이다. 클릭·키보드 동작은 없다.
- 증감은 소수 첫째 자리로 적는다. 비율은 `%p`, 건수·금액은 `%`. (PlaceWave 저장소/docs/dashboard.md §1 원칙 4)
- 증감 줄은 비어 있어도 높이를 유지해 칸끼리 값 줄이 맞는다.
- 스크린리더는 "증가 9.0%"처럼 방향을 글자로 읽는다. 화살표는 `aria-hidden`.

## 예외
- 값 문자열이 칸보다 길면 칸 안에서 잘린다. 큰 수는 쓰는 쪽에서 "4,530만"처럼 줄여 넘긴다.
- 칸 수가 열 수의 배수가 아니면 남는 자리가 선 색으로 보인다. `className`으로 열 수를 맞춘다.
- 숫자 포맷(만·억 단위, 소수 자리): 쓰는 쪽에서 처리한다.

## 인수 조건
- Given `delta { value: 9.0, unit: "%" }`, When 렌더한다, Then "▲ 9.0%"가 초록이다.
- Given `delta { value: 1.8, unit: "%p", good: "down" }`, When 렌더한다, Then "▲ 1.8%p"가 빨강이다.
- Given `delta { value: 0, unit: "%p" }`, When 렌더한다, Then 화살표 없이 회색 "0.0%p"다.
- Given `delta { value: null }`, When 렌더한다, Then "—"가 보인다.
- Given `delta` 없음, When 렌더한다, Then 증감 줄이 비어 있고 옆 칸과 값 높이가 같다.

## 측정
- 이 부품 자체에는 사용자 동작이 없다. 화면 단위 조회 이벤트는 쓰는 쪽에서 남긴다.
- `kpi_tile_help_opened` { metric_id } (가정): 원본은 이름 옆 `?`로 지표 정의를 연다. 붙이면 어떤 지표 정의를 자주 찾는지 본다.

## 범위 밖
- 지표 정의 팝오버(`?`)
- 증감 계산(직전 동일 길이 기간 비교)
- 칸 클릭 드릴다운
