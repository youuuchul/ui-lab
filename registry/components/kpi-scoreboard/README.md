# KPI 스코어보드

핵심 지표를 값·직전 기간 대비 증감·분모 한 줄로 한 줄에 늘어놓는 스코어보드.

데모 수치는 PlaceWave의 가상 플랫폼 데이터(시나리오로 생성한 합성 데이터)이며 실제 서비스 데이터가 아니다.

## Props
| 이름        | 타입        | 기본값                | 설명                                                                                  |
|-------------|-------------|-----------------------|---------------------------------------------------------------------------------------|
| `items`     | `KpiItem[]` | -                     | 칸 목록                                                                               |
| `caption`   | `string`    | -                     | 위 소제목. `<구획> · <비교 기준>` (예: "핵심 지표 · 직전 28일 대비")                  |
| `className` | `string`    | 2열, 48rem 이상 한 줄 | 칸 배치(grid 열). 스코어보드 자신의 폭 기준 컨테이너 쿼리(`@xl:grid-cols-3`)로 적는다 |

`KpiItem`
| 이름    | 타입                                                                  | 설명                                       |
|---------|-----------------------------------------------------------------------|--------------------------------------------|
| `label` | `string`                                                              | 지표 이름                                  |
| `value` | `string`                                                              | 표시용 값 ("6,314", "4,530만", "9.73%")    |
| `unit`  | `string`                                                              | 값 뒤 작은 단위 ("건", "명", "원")         |
| `delta` | `{ value: number \| null; unit: "%" \| "%p"; good?: "up" \| "down" }` | 직전 기간 대비. null은 "—", 생략하면 빈 줄 |
| `sub`   | `string`                                                              | 분모·기준일 한 줄 ("검색 9,713건 중")      |

## 구현 메모
- 화살표(▲▼)는 실제 증감 방향, 색은 좋아졌는지(`good`)를 따른다. 결과 0건 비율이 오르면 ▲ 빨강이다. 화살표와 스크린리더용 "증가/감소" 글자가 있어 색만으로 읽지 않는다.
- 소수 첫째 자리에서 0이 되면 화살표 없이 회색 `0.0%p`로 둔다.
- `dl` 안에 칸마다 `dt`(이름)와 `dd`(값·증감·보조)를 둔다. 숫자는 모두 `tabular-nums`.
- 열 수는 화면 폭이 아니라 스코어보드 폭으로 정한다(`@container`). 좁은 카드 안에 넣어도 칸이 눌리지 않는다.
- 칸 사이 선은 `gap-px` + 바탕색 `line`으로 그린다. 칸 수가 열 수의 배수가 아니면 빈 칸이 선 색으로 보이니 열 수를 맞춘다.
