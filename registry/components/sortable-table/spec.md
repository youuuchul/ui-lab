# 정렬 표 기능 명세
열 머리를 눌러 정렬하는 숫자 위주 데이터 표.

## 목적
- 의도 유형별·검색어별처럼 대상마다 같은 지표를 비교하고, 질문에 맞는 열로 줄을 세운다. (PlaceWave 저장소/docs/dashboard.md §2 검색 탭 표)

## 사용자 시나리오
1. 검색 담당자가 검색어 표를 결과 0건 내림차순으로 열어 실패가 큰 검색어부터 본다.
2. 같은 사람이 검색 수 열을 눌러 많이 찾는 검색어 순으로 바꾼다.

## 상태
| 상태      | 화면                                         | 들어오는 조건                       | 나가는 조건          |
|-----------|----------------------------------------------|-------------------------------------|----------------------|
| 정렬 없음 | 입력 순서                                    | `defaultSort` 없음                  | 열 머리 누름         |
| 내림차순  | 그 열 ▼, 진한 글자, `aria-sort="descending"` | 다른 열에서 누름, 오름차순에서 누름 | 같은 열 누름         |
| 오름차순  | 그 열 ▲, `aria-sort="ascending"`             | 내림차순에서 같은 열 누름           | 같은 열·다른 열 누름 |

## 동작
- 열 머리는 높이 40px 버튼이다. 키보드 Tab으로 가고 Enter·Space로 누른다.
- 숫자는 크기, 문자열은 한국어 사전 순(`localeCompare`).
- null은 "—"로 보이고 방향과 상관없이 맨 아래.
- `sortable: false` 열은 버튼이 아니라 글자다.

## 예외
- 같은 값끼리는 입력 순서를 유지한다(안정 정렬).
- 행이 많을 때 나누기·더 보기: 쓰는 쪽에서 처리한다.
- 숫자를 문자열로 넘기면 문자열 정렬이 된다. 쓰는 쪽에서 숫자로 넘긴다.

## 인수 조건
- Given `defaultSort { key: "zero", dir: "desc" }`, When 렌더한다, Then 결과 0건 23.3% 행이 맨 위이고 그 열 머리가 `aria-sort="descending"`이다.
- Given 결과 0건 내림차순, When 그 열 머리를 누른다, Then 오름차순으로 바뀐다.
- Given 검색 수 열이 정렬 아님, When 누른다, Then 검색 수 내림차순이 된다.
- Given null 칸이 있는 열, When 어느 방향으로 정렬한다, Then null 행이 맨 아래다.

## 측정
- `table_sorted` { table_id, column, direction } (가정): 정렬을 바꿀 때. 기본 정렬이 질문에 맞는지 판단한다.

## 범위 밖
- 행 선택·클릭 이동
- 열 너비 조절, 고정 열
- 페이지 나누기, 검색
