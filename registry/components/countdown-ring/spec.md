# 원형 카운트다운 기능 명세
남은 시간을 둘레 길이로 보여주는 원형 타이머.

## 목적
- 시간이 지나면 행동이 막히는 곳에서 남은 시간을 한눈에 보여준다.
- 경고 구간에 들어가면 색과 깜빡임으로 한 번 더 알린다. (출처: HeartTable AI 게임형 대화)

## 사용자 시나리오
1. 제한 시간이 있는 라운드에서 사용자가 남은 시간을 링의 길이와 숫자로 확인한다.
2. 남은 시간이 20% 미만이 되면, 사용자가 링이 빨갛게 바뀌고 깜빡이는 것을 보고 서두른다.

## 상태
| 상태 | 화면                       | 들어오는 조건             | 나가는 조건                     |
|------|----------------------------|---------------------------|---------------------------------|
| 진행 | 강조색 링, 흰 글자         | `progress >= urgentBelow` | `progress < urgentBelow`        |
| 경고 | 빨간 링, 글자 깜빡임       | `progress < urgentBelow`  | `progress`가 기준 이상으로 회복 |
| 소진 | 링이 비어 있고 라벨만 보임 | `progress`가 0 이하       | `progress`가 0 초과             |

- 소진은 경고의 한 경우다. 색과 깜빡임은 경고와 같다.
- `urgentBelow` 기본값은 0.2다.

## 동작
- 입력은 `progress`(남은 비율)와 `label`뿐이다. 클릭·키보드 동작은 없다.
- 링은 12시 방향에서 시작해 시계 방향으로 줄어든다.
- `progress`가 바뀌면 0.7초 선형 전환한다. 1초 간격 갱신에 맞춘 값이다.
- `role="timer"`와 `ariaLabel`(기본 "남은 시간")을 노출한다. 링은 `aria-hidden`이다.
- 숫자는 `tabular-nums`라 자릿수가 바뀌어도 폭이 흔들리지 않는다.

## 예외
- `progress`가 0~1 범위를 벗어나면 링 길이는 0~1로 자르지만, 경고 판정은 원래 값으로 한다. 쓰는 쪽에서 범위를 맞춘다.
- `prefers-reduced-motion`: 링 전환과 글자 깜빡임을 끈다.
- 시간 계산, 일시정지, 종료 처리: 쓰는 쪽에서 처리한다. 컴포넌트는 비율과 글자만 받는다.
- 1초보다 짧은 간격으로 `progress`를 바꾸면 전환과 겹쳐 떨린다. 쓰는 쪽에서 간격을 지킨다.
- `label` 형식(분:초 등): 쓰는 쪽에서 만든다.

## 인수 조건
- Given `progress=1`, `label="0:10"`, When 렌더한다, Then 링이 가득 차 있고 강조색이다.
- Given `progress=0.5`, When 렌더한다, Then 링이 절반이고 시계 방향으로 줄어든 모양이다.
- Given `progress=0.19`, `urgentBelow` 기본값, When 렌더한다, Then 링과 글자가 빨간색이고 글자가 깜빡인다.
- Given `progress=0.2`, When 렌더한다, Then 경고가 아니다. (미만에서만 경고)
- Given `progress=0`, When 렌더한다, Then 링이 비어 있고 경고 모양이다.
- Given 모션 줄이기 설정, When `progress`가 바뀐다, Then 링이 전환 없이 바뀌고 글자가 깜빡이지 않는다.

## 측정
- `timer_urgent_entered` { remaining_ratio, round_id } : 경고 구간에 처음 들어갈 때 쓰는 쪽에서 남긴다.
- `timer_expired` { round_id, action_taken } : 소진 시점에 남긴다. `action_taken`은 시간 안에 행동했는지 여부.

## 범위 밖
- 시간 흐름 계산과 카운트 루프
- 시작·정지·재설정 컨트롤
- 종료 후 동작(자동 제출, 라운드 전환)
- 소리·진동 알림
