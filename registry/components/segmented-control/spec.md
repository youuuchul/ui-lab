# 세그먼트 컨트롤 기능 명세
2~5개 선택지 중 하나를 고르는 붙은 버튼 묶음. 선택 표시가 미끄러지며 옮겨 간다.

## 목적
- 같은 내용을 기간·보기 방식으로 바꿔 볼 때 현재 선택과 다른 선택지를 한 줄로 보여준다.

## 사용자 시나리오
1. 방문자 통계에서 "일·주·월·년" 중 "월"을 누르면 선택 표시가 옮겨 가고 막대 그래프가 바뀐다.
2. 키보드 사용자가 화살표로 "목록"에서 "지도"로 옮기면 바로 선택된다.

## 상태
| 상태       | 화면                   | 들어오는 조건 | 나가는 조건      |
|------------|------------------------|---------------|------------------|
| 선택됨     | 표시판 아래, 진한 글자 | 값 일치       | 다른 선택지 선택 |
| 선택 안 됨 | 흐린 글자              | 값 불일치     | 선택             |
| 호버       | 글자 한 단계 진해짐    | 포인터 올림   | 포인터 벗어남    |
| 포커스     | 바깥 링                | 키보드 포커스 | 포커스 이동      |
| 비활성     | 투명도 50%             | disabled=true | disabled=false   |

## 동작
- 클릭: 선택지를 선택한다. 이미 선택된 것을 누르면 `onChange`를 호출하지 않는다.
- 키보드: 선택된 항목만 Tab으로 들어간다. ←·↑는 이전, →·↓는 다음으로 옮기고 처음과 끝은 이어진다. Home·End는 처음·끝이다. 옮기는 즉시 선택되고 포커스도 따라간다.
- 선택 표시는 칸 번호만큼 `translateX`로 0.3초 동안 미끄러진다. 칸은 모두 같은 폭이다.
- `value`를 넘기면 제어, 아니면 `defaultValue`(없으면 첫 선택지)를 쓴다.
- `size=sm`은 높이 28px이고 투명 영역으로 터치 40px를 맞춘다.
- 동작 줄이기에서는 표시판이 바로 옮겨 간다.

## 예외
- 비활성: 클릭·키보드 모두 선택이 바뀌지 않는다.
- 제어 모드에서 `value`가 선택지에 없으면 첫 칸이 선택된 모양으로 보인다. 값 검증은 쓰는 쪽에서 한다.
- 제어 모드에서 `onChange`가 값을 갱신하지 않으면 선택은 그대로다.
- 선택지 개수(2~5개)와 라벨 길이는 검사하지 않는다. 라벨은 한 줄에서 말줄임된다.
- 선택지 빈 배열은 처리하지 않는다. 쓰는 쪽에서 최소 한 개를 넘긴다.

## 인수 조건
- Given "주" 선택, When "월"을 클릭한다, Then 표시판이 "월" 칸으로 옮겨 가고 `onChange("month")`가 한 번 호출된다.
- Given "주" 선택, When "주"를 다시 클릭한다, Then `onChange`가 호출되지 않는다.
- Given "일" 선택에 포커스, When ←를 누른다, Then 마지막 선택지가 선택되고 포커스가 그 칸으로 간다.
- Given 포커스가 컨트롤 밖, When Tab으로 들어온다, Then 선택된 항목에만 포커스가 가고 다른 항목은 건너뛴다.
- Given `disabled=true`, When 클릭하거나 화살표를 누른다, Then 선택이 바뀌지 않는다.
- Given `label="집계 기간"`, When 스크린리더로 읽는다, Then 라디오 그룹 이름으로 읽히고 선택된 항목이 `aria-checked=true`다.

## 측정
- `segment_changed` { control_id, from, to, input: "pointer" | "keyboard" }
- 선택 결과로 바뀐 보기(예: 기간)는 쓰는 쪽 화면 조회 이벤트에 속성으로 남긴다.

## 범위 밖
- 페이지 이동 메뉴(탭·내비게이션을 쓴다).
- 6개 이상 선택지, 긴 라벨.
- 다중 선택.
- 선택 결과에 따른 데이터 로딩과 실패 처리.
