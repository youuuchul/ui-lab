# KPI 개요 대시보드

기간을 바꾸면 핵심 지표 스코어보드와 북극성 지표 추이·분해 타일이 함께 바뀌는 개요 화면. PlaceWave 대시보드의 개요 탭에서 필터·나머지 추이 카드를 뺀 조합이다.

데모 수치는 PlaceWave의 가상 플랫폼 데이터(시나리오로 생성한 합성 데이터)이며 실제 서비스 데이터가 아니다.

## 조합
| 자리                                      | 컴포넌트                                          |
|-------------------------------------------|---------------------------------------------------|
| 기간 선택 7일·28일·90일                   | [세그먼트 컨트롤](#/components/segmented-control) |
| 핵심 지표 6칸, 추이 카드 오른쪽 분해 타일 | [KPI 스코어보드](#/components/kpi-scoreboard)     |
| 결제 추이(신청 보조선, 전기 점선)         | [추이 선 차트](#/components/trend-chart)          |

## Props
| 이름            | 타입                                   | 기본값  | 설명                                      |
|-----------------|----------------------------------------|---------|-------------------------------------------|
| `asOf`          | `{ label; items: { label; value }[] }` | -       | 기간과 무관한 기준일 현황 줄              |
| `periods`       | `OverviewPeriod[]`                     | -       | 기간마다 `range`·`caption`·`kpis`·`trend` |
| `defaultPeriod` | `string`                               | 첫 기간 | 처음 선택                                 |

## 구현 메모
- 기간 하나에 화면 전체 값이 묶여 있다. 기간을 바꾸면 스코어보드·추이·분해 타일·기간 표시가 한 번에 바뀐다.
- 입자는 원본 규칙을 따른다. 14일 이하 일별, 그 이상 주별(기간 시작일부터 7일씩). 전기는 직전 같은 길이 기간을 같은 x 위치에 점선으로 겹친다.
- 분해 타일은 결제·객단가·거래액이다. 거래액 = (결제 − 환불) × 객단가로 읽히게 북극성 지표 바로 아래 둔다.

## 실제 서비스에서 바꿀 곳
- `periods`: 마트에서 분자·분모를 기간별로 합산해 만든다. 사람 지표(방문자)는 일별 값을 더하지 말고 기간 고유 수를 따로 센다.
- 차트 클릭 드릴다운(구간 → 그 기간), 채널·플랫폼·회원 필터, 나머지 추이 카드(방문자·가입·구독·파트너·매출 구성)는 원본에 있고 여기서는 뺐다.
