# PetGlobe 첫 화면

창가 그림 속 유리구에 은하수 글로브를 겹치고, 세 장면으로 서비스를 소개하는 온보딩 첫 화면.

## 조합
| 자리                              | 컴포넌트                                                          |
|-----------------------------------|-------------------------------------------------------------------|
| 그림 속 유리구 안의 움직이는 하늘 | [은하수 글로브](#/item/components/galaxy-globe) (`chrome="none"`) |

## 흐름
1. 장면 1: 별빛 하나가 날아와 켜진다 (`lightUp`). 뒤로 돌아오면 이미 켜진 상태다.
2. 장면 2: 별빛 40개가 모여든다 (`gather`).
3. 장면 3: 은하수 밀도층이 10만 개로 차오르고 무지갯빛 비율이 올라간다 (`communityAnimate`).
- 3.6초마다 자동으로 넘어간다. 화면 오른쪽 절반을 탭하면 다음, 왼쪽 절반은 이전, 좌우 스와이프(40px 초과, 가로가 더 클 때), 점 버튼, 방향키로도 넘긴다. 별빛을 탭한 것은 넘김으로 보지 않는다.
- 동작 줄이기 설정에서는 켜짐·모임 연출 없이 결과 상태만 보여준다.

## 구현 메모
- 그림(2:3)에서 최소제곱으로 측정한 유리구 중심·지름(`GLASS`)에 맞춰 글로브 크기와 자리를 계산한다. 그림을 바꾸면 다시 측정해야 한다.
- 그림 위·아래 가장자리는 마스크로 흐려 배경색(밤하늘 `#16172F` → 창턱 `#231715`)에 잇는다.
- 원본은 화면 높이에 맞춰 장면을 배치하고(세로·가로·낮은 화면 분기), 데스크톱에서는 그림을 흐려 양옆에 늘린다. 여기서는 컨테이너 폭 기준 한 가지 배치만 남겼다.
- 원본의 영문 세리프(Cormorant Garamond)·한글 명조(Gowun Batang)는 `font-serif` 기본값으로 대신했다. 실서비스의 실제 은하수 개수 API는 `community` prop으로 바꿨다.
