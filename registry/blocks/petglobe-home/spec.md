# PetGlobe 첫 화면 기획 문서
창가 그림 속 유리구에 은하수 글로브를 겹치고, 세 장면으로 서비스를 소개하는 온보딩 첫 화면.

## PRD 요약
### 문제
- 반려동물 서비스는 일정·건강 기록, 커뮤니티, 펫로스 추모 중 한 영역에 머문다. 돌봄과 기억, 이별을 한 흐름으로 잇는 서비스는 드물다. (PetGlobe 저장소/pet_service_brand_concept.md 2)
- 추억을 남기는 행동이 개인 기록으로만 닫히면 "나만 쓰는 일기장"과 구분되지 않는다. (PetGlobe 저장소/docs/backlog.md GLOBE-01)
- 첫 방문자는 가입 없이 바로 시작한다. 첫 화면에서 이 서비스가 무엇을 쌓는 곳인지 전해야 한다. (PetGlobe 저장소/README.md, 가정: 첫 화면이 그 역할을 맡는다)

### 대상 사용자
- 반려견·반려묘를 키우며 일정 관리와 정서적 돌봄을 함께 원하는 보호자 (pet_service_brand_concept.md 5)
- 이별을 준비하거나 이별 이후 기억을 정리하려는 보호자 (같은 문서)

### 목표 지표
- 출처 문서에 첫 화면 지표가 없다. 아래는 모두 (가정).
- 시작 전환율: 시작 버튼 클릭 수 / 첫 화면 노출 수
- 장면 3 도달률: 마지막 장면을 본 수 / 첫 화면 노출 수
- 건너뛰기 비율: 건너뛰기 클릭 수 / 첫 화면 노출 수

### 해결 방향
- 창가의 스노우글로브 그림 속 유리구 자리에 움직이는 은하수 글로브를 겹친다.
- 세 장면으로 "추억 하나 → 별빛 하나 → 모두의 밤하늘"을 보여준다. 장면마다 한 줄만 둔다.
- 자동으로 넘어가되, 직접 넘기면 멈춘다. 시작 버튼은 장면과 상관없이 늘 같은 자리에 둔다.

### 범위
- 담은 것: 세 장면 연출, 자동·수동 넘김, 건너뛰기, 시작 버튼, 동작 줄이기 대응
- 뺀 것과 이유 (블록 README 기준)
  - 화면 높이별 배치 분기(세로·가로·낮은 화면), 데스크톱 양옆 흐림 확장: 컨테이너 폭 기준 한 가지 배치만 남김
  - 원본 영문 세리프·한글 명조 글꼴: `font-serif` 기본값으로 대신함
  - 실제 은하수 개수 API: `community` prop으로 바꿈

### 위험과 확인할 것
- 화면에 반려동물의 흔적이 없어 무슨 서비스인지 알아보기 어렵다는 지적이 원본에 있다. (backlog.md VIS-01)
- 장면 3의 은하수 개수와 무지갯빛 비율은 미리 보기 값이다. 실제 집계처럼 읽히지 않게 한다.
- 추모 맥락이라 숫자가 게임 지표처럼 읽히면 안 된다. 랭킹·달성 같은 표현을 넣지 않는다. (backlog.md GLOBE-01)
- 배경 그림을 바꾸면 유리구 중심·지름(`GLASS`)을 다시 재야 한다.

## 유저 스토리
- 처음 온 보호자로서, 이 서비스가 무엇을 쌓는 곳인지 알기 위해 짧은 장면을 보고 싶다.
  - Given 첫 화면, When 글로브 준비가 끝난다, Then 장면 1에서 별빛 하나가 날아와 켜진다.
  - Given 장면 1, When 3.6초가 지난다, Then 장면 2로 넘어가 별빛 40개가 모여든다.
- 빨리 시작하고 싶은 보호자로서, 소개를 다 보지 않기 위해 건너뛰거나 바로 시작하고 싶다.
  - Given 장면 1, When 건너뛰기를 누른다, Then 장면 3으로 가고 자동 진행이 멈춘다.
  - Given 어느 장면이든, When 시작 버튼을 누른다, Then `onPrimary`가 호출된다.
- 장면을 직접 보고 싶은 보호자로서, 내 속도로 보기 위해 탭·스와이프로 넘기고 싶다.
  - Given 장면 2, When 화면 왼쪽 절반을 탭한다, Then 장면 1로 돌아가고 별빛은 이미 켜진 상태다.
  - Given 장면 2, When 글로브 안의 별빛을 탭한다, Then 장면이 넘어가지 않는다.

## 기능 명세
### 상태
| 상태      | 화면                   | 들어오는 조건              | 나가는 조건      |
|-----------|------------------------|----------------------------|------------------|
| 준비 중   | 그림, 글로브 그리는 중 | 마운트                     | 글로브 준비 완료 |
| 장면 1    | 별빛 하나가 켜짐       | 준비 완료, 이전으로        | 다음, 자동 진행  |
| 장면 2    | 별빛 40개가 모임       | 다음, 자동, 점 선택        | 다음, 이전, 자동 |
| 장면 3    | 은하수 밀도층 가득     | 다음, 자동, 건너뛰기       | 이전, 점 선택    |
| 수동 진행 | 자동 넘김 멈춤         | 탭·스와이프·점·키·건너뛰기 | 없음             |

### 동작
- 자동 진행: 글로브 준비 뒤 3.6초마다 다음 장면. 마지막 장면에서 멈춘다.
- 넘김: 오른쪽 절반 탭은 다음, 왼쪽 절반은 이전. 가로 스와이프(40px 초과, 가로가 더 클 때), 점 버튼, 좌우 방향키도 같다.
- 장면 문구는 바뀔 때마다 아래에서 올라오며 나타나고, `aria-live`로 읽힌다.
- 마지막 장면에서는 건너뛰기 자리에 한 줄 문구를 둔다. 같은 높이라 시작 버튼이 움직이지 않는다.
- 글로브 크기와 자리는 그림에서 잰 유리구 비율로 계산하고, 그림 테두리가 보이게 살짝 작게 그린다.

### 예외
- 동작 줄이기: 자동 진행과 켜짐·모임 연출 없이 장면별 결과 상태만 보여준다.
- 40px 이하 이동과 세로 스와이프: 넘김으로 보지 않는다. 짧은 이동이면 탭으로 처리한다.
- 별빛 위 탭: 넘기지 않는다.
- 장면 1로 돌아옴: 별빛을 다시 날리지 않고 켜진 상태로 둔다.
- 시작 이후 이동(등록 화면 등), 실제 은하수 개수 조회와 실패 처리: 쓰는 쪽에서 처리.
- 첫 화면을 보여줄지(계정 유무) 판단: 쓰는 쪽에서 처리.
