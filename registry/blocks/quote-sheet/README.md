# 견적 안내 시트

업무 묶음별로 범위·결과물·기간을 한 줄씩 정리하고, 참고 사항과 진행 순서를 붙이는 안내 페이지. 메일 회신 링크나 문의 직후 보여주는 용도.

## Props
| 이름          | 타입                                                   | 기본값     | 설명                        |
|---------------|--------------------------------------------------------|------------|-----------------------------|
| `kicker`      | `string`                                               | -          | 제목 위 작은 강조 줄        |
| `title`       | `string`                                               | -          | 제목                        |
| `sub`         | `string`                                               | -          | 제목 아래 설명              |
| `groups`      | `{ name; offers: { title; what; output; value }[] }[]` | -          | 업무 묶음과 줄              |
| `valueLabel`  | `string`                                               | `"기간"`   | 오른쪽 숫자 칸 라벨         |
| `outputLabel` | `string`                                               | `"결과물"` | 결과물 칸 라벨              |
| `notes`       | `string[]`                                             | -          | 표 아래 참고 사항           |
| `steps`       | `{ k; v }[]`                                           | -          | 진행 순서 카드. 번호는 자동 |
| `footer`      | `ReactNode`                                            | -          | 하단 버튼·링크              |

## 구현 메모
- 줄은 넓은 화면에서 `설명 | 결과물 | 숫자` 3칸, 좁은 컨테이너(폭 36rem 미만, 컨테이너 쿼리)에서는 결과물이 아래 줄로 내려가고 숫자는 오른쪽 위에 남는다.
- 진행 순서 카드는 `auto-fit`으로 개수만큼 한 줄에 나눠 앉는다.
- 상태가 없어 서버 컴포넌트로도 쓸 수 있다 (`"use client"` 없음).
