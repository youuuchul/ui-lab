# 검색 품질 대시보드

검색 성공률·결과 0건 비율 같은 검색 품질 지표를 기간별 스코어보드, 일별 추이, 의도 유형별 표로 보는 화면. PlaceWave 대시보드의 검색 탭에서 필터·검색어 표를 뺀 조합이다.

데모 수치는 PlaceWave의 가상 플랫폼 데이터(시나리오로 생성한 합성 데이터)이며 실제 서비스 데이터가 아니다.

## 조합
| 자리                                | 컴포넌트                                          |
|-------------------------------------|---------------------------------------------------|
| 기간 선택 7일·28일·90일             | [세그먼트 컨트롤](#/components/segmented-control) |
| 검색 지표 6칸                       | [KPI 스코어보드](#/components/kpi-scoreboard)     |
| 검색 성공률·결과 0건 비율 일별 추이 | [추이 선 차트](#/components/trend-chart)          |
| 의도 유형별 표                      | [정렬 표](#/components/sortable-table)            |

## Props
| 이름            | 타입             | 기본값  | 설명                              |
|-----------------|------------------|---------|-----------------------------------|
| `periods`       | `SearchPeriod[]` | -       | 기간마다 `kpis`·`daily`·`intents` |
| `defaultPeriod` | `string`         | 첫 기간 | 처음 선택                         |

## 구현 메모
- 검색 성공률 = (1 − 결과 0건 비율) × 결과 클릭률. 세 값을 같은 화면에 두어 성공률 변화가 어느 쪽에서 왔는지 가른다.
- 결과 0건 비율·재검색률·평균 첫 클릭 순위는 낮을수록 좋아 증감 색이 반대다.
- 90일로 바꾸면 6~7월 20%대이던 결과 0건 비율이 7/13·7/27 두 번에 걸쳐 내려오는 흐름과, 9/1~9/4 다시 튄 구간이 같은 차트에 보인다.
- 의도 유형별 표는 검색 수 내림차순으로 시작하고, 결과가 없는 "해석 못 함"의 결과 클릭률·첫 클릭 순위는 —로 맨 아래 정렬된다.

## 실제 서비스에서 바꿀 곳
- `periods`: 서버 검색 요청 로그와 클릭 로그를 요청 id로 붙인 일 마트에서 분자·분모를 합산해 나눈다.
- 실패 검색어 표(검색 20건 이상·결과 0건 30% 이상, 평가 편입일)는 원본에 있고 여기서는 뺐다. [정렬 표](#/components/sortable-table) 데모가 그 표의 모양이다.
