# 검색 품질 대시보드 기획 문서
검색 성공률·결과 0건 비율 같은 검색 품질 지표를 기간별 스코어보드, 일별 추이, 의도 유형별 표로 보는 화면.

## PRD 요약
### 문제
- 검색이 어디서 실패하고, 랭킹 개선이 실패를 줄였는지 답해야 한다. (PlaceWave 저장소/docs/metrics.md 탭이 답하는 질문 · 검색)
- 클라이언트 분석 이벤트는 수집 누락이 있어 분모로 쓰면 비율이 흔들린다. 서버 요청 로그를 분모로 쓴다. (PlaceWave 저장소/docs/dashboard.md §3d)
- 결과 클릭률만 보면 결과 0건이 줄 때 분모가 바뀌어 나빠진 것처럼 보인다. 검색 1건 기준 성공률을 함께 둔다. (metrics.md Q12)

### 대상 사용자
- 검색 품질을 주 단위로 보는 검색 담당자
- 실패 검색어를 평가 데이터로 넘기는 평가 운영 담당자

### 목표 지표
- 검색 성공률 Q12 = 클릭된 검색 ÷ 검색 = (1 − 결과 0건 비율) × 결과 클릭률. (metrics.md 검색)
- 결과 0건 비율 Q03, 평균 첫 클릭 순위 Q05, 재검색률 Q07, 검색 세션 신청 전환 Q08. (같은 문서)
- 화면 성공 기준: 결과 0건이 튄 날 이 화면에서 원인 의도 유형까지 찾는 시간 (가정)

### 해결 방향
- 기간 선택 → 검색 지표 6칸 → 성공률·결과 0건 일별 추이 → 의도 유형별 정렬 표.
- 실험 구간 표식은 두지 않는다. 실험 맥락은 보고서에서만 다룬다. (dashboard.md §2 검색 탭)

### 범위
- 담은 것: 기간 전환(7·28·90일), 스코어보드 6칸, 일별 추이 2선, 의도 유형별 표(정렬)
- 뺀 것과 이유
  - 채널·플랫폼·회원 필터: 검색 이용자(기간 고유 사람) 재계산이 필요해 뺌
  - 검색어 표(실패 검색어 강조, 평가 편입일): 기간마다 행이 수십~백여 개라 데모 범위 밖. 표 모양은 정렬 표 데모로 보인다
  - 랭킹 A/B 결과, 라벨링 운영: 원본도 보고서 페이지에 둔다

### 위험과 확인할 것
- 의도 유형은 검색어 분류기 결과다. 분류기가 바뀌면 유형별 추이가 끊긴다. (metrics.md 검색)
- 9/1~9/4 결과 0건 급증처럼 하루 단위 회귀는 주별로 보면 묻힌다. 일별 입자를 유지한다.
- 평균 첫 클릭 순위는 클릭된 검색만 분모라 클릭이 줄면 좋아 보일 수 있다. 성공률과 함께 읽는다.

## 단계 분리

|------|------------------------------------|----------------------------------|
| MVP  | 스코어보드, 일별 추이              | 결과 0건 급증일을 찾을 수 있는가 |

| v3   | 세그먼트 필터                      | 플랫폼별 차이                    |

## 유저 스토리
- 검색 담당자로서, 이번 기간 검색 품질이 나빠졌는지 알기 위해 지표 6칸을 보고 싶다.
  - Given 28일, When 화면을 연다, Then 결과 0건 비율 5.2% ▲ 1.8%p가 빨간색, 보조 줄 "검색 9,713건 중"이 보인다.
  - Given 검색 세션 신청 전환 증감 0.0%p, When 렌더한다, Then 화살표 없이 회색으로 보인다.
- 회귀를 찾는 검색 담당자로서, 언제 실패가 늘었는지 보기 위해 일별 추이를 보고 싶다.
  - Given 28일 추이, When 9/2로 화살표 이동한다, Then 결과 0건 20.9%, 성공률 35.6%가 읽힌다.
  - Given 90일로 전환, When 추이를 본다, Then 90개 일별 구간이 점 없이 선으로 그려지고 x축 라벨이 겹치지 않는다.
- 원인을 좁히는 담당자로서, 어느 의도 유형에서 실패가 나는지 보기 위해 표를 정렬하고 싶다.
  - Given 의도 유형별 표(검색 수 내림차순), When "결과 0건" 머리를 누른다, Then 해석 못 함(100.0%)이 맨 위, 상권(9.6%)이 다음이다.
  - Given 결과 클릭률 열로 정렬, When 어느 방향이든, Then "해석 못 함"(—)이 맨 아래다.

## 기능 명세
### 상태
| 상태      | 화면                         | 들어오는 조건     | 나가는 조건          |
|-----------|------------------------------|-------------------|----------------------|
| 기간 표시 | 선택 기간의 지표·추이·표     | 마운트, 기간 선택 | 다른 기간 선택       |
| 구간 확인 | 추이 세로선·툴팁             | 포인터, 화살표    | 이탈, Esc, 기간 전환 |
| 정렬 변경 | 표 순서, 머리 ▲▼·`aria-sort` | 머리 누름         | 다른 머리 누름       |

- 기간을 바꿔도 표 정렬 상태는 유지한다.

### 동작
- 검색 이용자: 기간 고유 사람. 나머지는 서버 요청 단위 분자·분모를 기간 합산 후 나눈다. (dashboard.md §3d)
- 증감: 비율은 %p, 검색 이용자는 %, 평균 첫 클릭 순위는 %. 결과 0건 비율·재검색률·첫 클릭 순위는 낮을수록 좋음. (dashboard.md §1 원칙 4)
- 추이: 일별 검색 성공률, 결과 0건 비율(0~100%).
- 의도 유형별 표 열: 검색 수, 성공률, 결과 0건, 결과 클릭률, 첫 클릭 순위, 재검색률. 기본 검색 수 내림차순.

### 예외
- 결과가 1건도 없는 유형(해석 못 함): 결과 클릭률·첫 클릭 순위를 —로 둔다.
- 검색이 0건인 날: 비율이 정의되지 않으므로 쓰는 쪽에서 null로 넘겨 선을 끊는다.
- 데이터 로딩·오류: 쓰는 쪽에서 처리한다.
