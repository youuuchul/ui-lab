# 퍼널 분석 대시보드

전환 스코어보드 → 단계 전환율 추이 → 세그먼트별 퍼널 → 생키 다이어그램 순서로 이탈 지점을 좁혀 가는 화면. PlaceWave 대시보드의 퍼널 탭에서 필터·오디언스 카드·요일×시간대 히트맵을 뺀 조합이다.

데모 수치는 PlaceWave의 가상 플랫폼 데이터(시나리오로 생성한 합성 데이터)이며 실제 서비스 데이터가 아니다.

## 조합
| 자리                                                       | 컴포넌트                                      |
|------------------------------------------------------------|-----------------------------------------------|
| 전체 전환율·최대 이탈 단계·가장 크게 변한 단계·탐색 도달률 | [KPI 스코어보드](#/components/kpi-scoreboard) |
| 단계 전환율 추이                                           | [추이 선 차트](#/components/trend-chart)      |
| 세그먼트별 퍼널                                            | [퍼널 히트맵 표](#/components/funnel-heatmap) |
| 경로 탐색                                                  | [생키 다이어그램](#/components/path-sankey)   |

## Props
| 이름        | 타입                               | 기본값 | 설명                    |
|-------------|------------------------------------|--------|-------------------------|
| `range`     | `string`                           | -      | 기간 표시               |
| `caption`   | `string`                           | -      | 스코어보드 소제목       |
| `kpis`      | `KpiItem[]`                        | -      | 스코어보드 칸           |
| `stepTrend` | `{ note; labels; series }`         | -      | 단계 전환율(0~100) 추이 |
| `segments`  | `{ steps; rows }`                  | -      | 세그먼트별 도달률       |
| `path`      | `{ note; columns; links; groups }` | -      | 생키 다이어그램 데이터  |

## 구현 메모
- 위에서 아래로 "어느 단계가 → 언제부터 → 어느 집단에서 → 어떤 경로로"를 답한다. 숫자로 지점을 좁힌 뒤 생키로 내려간다.
- 추이·생키는 포인터와 키보드로 값을 읽는다. 세그먼트 표는 숫자가 칸 안에 있어 따로 조작이 없다.
- 데모 기간은 28일(8/24~9/20) 하나다. 생키는 원본 5열 중 앞 4열, 화면은 상위 5개 + 기타·이탈로 묶었다.

## 실제 서비스에서 바꿀 곳
- 단계 수는 같은 날 누적 조건의 고유 사람으로 센다. 일별 사람 수 합은 사람·일이라 단계 표에 쓰지 않는다.
- 경로 `links`는 세션별 화면 순서를 step·from·to로 집계한다. 열마다 상위 화면만 남기고 나머지는 기타로 묶는다.
