# 3D 역량 그래프 히어로

프로젝트·역량·영역을 노드로 잇는 3D 힘 그래프를 첫 화면 배경으로 깔고 제목을 겹치는 블록. d3-force-3d로 배치하고 Canvas 2D에 원근 투영해 그린다 (WebGL 없음).

## 파일
| 파일 | 역할 |
|---|---|
| `ForceGraphHero.tsx` | React 래퍼. 무대 + 제목 오버레이(`children`) |
| `graph.ts` | 엔진 `ForceGraph`: 시뮬레이션·투영·그리기·조작 |
| `d3-force-3d.d.ts` | d3-force-3d 타입 선언 (패키지에 타입이 없음) |

## Props
| 이름 | 타입 | 기본값 | 설명 |
|---|---|---|---|
| `data` | `GraphInput` | - | `{ nodes: { id, label, color, big? }[], links: { source, target }[], order? }` |
| `children` | `ReactNode` | - | 그래프 위 제목 영역 (포인터는 그래프로 통과) |
| `entry` | `"settle" \| "timelapse"` | `"settle"` | 진입 연출 |
| `ink` / `halo` | `string` | `#f2f2f2` / `#1b1b1b` | 선·라벨 색 / 라벨 테두리(바탕색) |

`color`는 `#rrggbb`만 받는다 (음영 계산). `data`는 컴포넌트 밖 상수나 `useMemo`로 고정한다 (바뀌면 그래프를 새로 만든다).

## 동작
- 진입 `settle`: 배치를 미리 300틱 계산해 자리를 잡은 뒤, `order` 순서대로 노드당 20ms 간격으로 제자리에서 떠오른다(0.35초). `timelapse`: 12단계로 나눠 이웃 근처에서 생기며 퍼지고, 끝나면 화면에 맞춰 확대된다.
- 자동 회전: 천천히 출발(약 1.5초), 노드에 올리면 빠르게 멈춘다(약 0.4초). 끌기·조작이 끝나고 1.2초 뒤 다시 돈다.
- 노드에 올리면 이웃만 남기고 나머지는 20%로 흐려진다. 연결선은 그 노드 색으로 강조.
- 마우스 위치로 살짝 기울어지는 시차, 끌어서 회전.
- 깊이에 따라 투명도(뒤쪽 30%), 구는 왼쪽 위 빛 기준 방사형 음영.
- 라벨은 노드 아래에 놓고, 겹치면 우선순위(호버·이웃 > `big` > 연결 수)가 낮은 쪽을 숨긴다. 작은 노드 라벨은 화면에서 작아지면 사라진다.
- 화면 밖이면 그리기를 멈추고, 할 일이 없으면 프레임 루프를 쉰다. 모션 줄이기면 최종 배치를 바로 그리고 돌지 않는다.

## 구현 메모
- 원본(portfolio-site 첫 화면 그래프, 약 1,400줄)에서 노드 모양(결정체·팔면체), 필터·고정·노드 카드, 조이스틱 회전, 스크롤 연동, 핀치 줌, 라벨 4방향 배치를 뺐다. 첫 화면에 필요한 진입·회전·호버만 남겼다.
- 의존성: `d3-force-3d`.
