# 사례 바인더

그룹 탭과 자동으로 넘어가는 사례 배너, 누르면 뜨는 장표 팝업을 묶은 블록. 경력·프로젝트 사례처럼 "묶음 → 사례 → 상세" 3단 구조에 쓴다.

## Props
| 이름           | 타입                      | 기본값        | 설명                                         |
|----------------|---------------------------|---------------|----------------------------------------------|
| `groups`       | `{ id; name; period? }[]` | -             | 탭. 고른 탭만 이름 옆에 `period`가 펼쳐짐    |
| `pages`        | `BinderPage[]`            | -             | 배너. 순서대로 돌며, 그룹은 `groupId`로 연결 |
| `autoplay`     | `number`                  | `5000`        | 자동 넘김 간격(ms), `0`이면 끔               |
| `pointerLabel` | `string`                  | `"상세 보기"` | 가운데 배너 위에서 커서 대신 따라다니는 라벨 |

`BinderPage`: `{ id, groupId, title, when?, lead: { value, label }, preview?, detail }`. `preview`는 배너 오른쪽 그림, `detail`은 팝업 내용.

## 동작
- 탭을 누르면 그 그룹의 첫 사례로 간다. 밑줄은 `layoutId`로 탭 사이를 미끄러진다. 탭 줄이 넘치면 고른 탭이 보이게 가로 스크롤.
- 배너는 모두 한 칸(grid area)에 겹쳐 두고 `transform`으로만 옮긴다. 배너끼리 높이가 같아 넘겨도 아래 레이아웃이 출렁이지 않는다.
- 양옆 배너는 컨테이너 바깥 여백(화면 끝까지 남는 폭)에 흐리게 걸친다. 간격은 24px 이하.
- 끌기: 가로 8px부터 끌기, 배너 폭 15%(최대 80px) 넘게 끌면 넘김. 끌기로 끝난 누름은 클릭으로 치지 않는다.
- 클릭: 가운데 = 팝업, 옆 = 그 배너로 이동. 키보드: 사례 영역에서 좌우 화살표·Enter, 탭 줄에서 좌우 화살표·Home·End(탭과 사례 영역은 `tabpanel`로 연결).
- 자동 넘김은 정지 버튼(`aria-pressed`)·마우스 올림·터치 접촉·키보드 포커스·끄는 중·팝업 열림·모션 줄이기·화면 절반 미만 노출이면 멈춘다.
- 팝업은 `<dialog>` `showModal()`. 닫기 버튼·바깥(배경) 클릭·Esc로 닫히고(장표 안쪽을 눌러도 닫히지 않는다), 열린 동안 페이지 스크롤을 잠근다.

## 구현 메모
- 원본(웹 포트폴리오 실무 경력 섹션)의 주소 해시 연동, 구성도 축소 맞춤, 수치 컴포넌트는 뺐다. 수치·그림은 `lead.value`·`preview`에 ReactNode로 넣는다.
- 의존성: `motion`.
