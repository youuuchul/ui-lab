# 사례 바인더 기획 문서
탭·배너 캐러셀·팝업으로 사례를 묶어 보여주는 바인더.

## PRD 요약
### 문제
- PDF는 페이지 단위라 경력 사례를 넘겨 봐야 한다. 웹 버전은 스크롤 흐름 안에서 사례를 훑게 한다. (웹 포트폴리오 저장소/HANDOFF.md 목표 1)
- 채용 담당자는 여러 사례를 짧게 훑고, 관심 있는 것만 깊게 본다. (가정)
- 사례마다 분량이 달라 넘길 때 아래 레이아웃이 출렁이면 읽기 흐름이 끊긴다. (가정)

### 대상 사용자
- 경력 사례를 훑는 채용 담당자
- "묶음 → 사례 → 상세" 3단 구조의 내용을 싣는 사람

### 목표 지표
- 출처 문서에 정의된 지표가 없다. 아래는 모두 (가정).
- 상세 열람률: 팝업을 한 번 이상 연 방문 수 / 바인더 노출 방문 수
- 사례 도달 수: 방문당 가운데에 온 서로 다른 사례 수

### 해결 방향
- 그룹 탭 아래에 사례 배너를 두고 자동으로 넘긴다. 양옆 배너는 여백에 흐리게 걸쳐 다음이 있음을 보인다.
- 가운데 배너를 누르면 장표 팝업, 옆 배너를 누르면 그 배너로 간다.
- 사용자가 머무는 신호(올림·접촉·포커스·팝업)가 있으면 자동 넘김을 멈춘다.

### 범위
- 담은 것: 그룹 탭, 자동 넘김 배너, 끌기, 키보드 조작, 정지 버튼, 장표 팝업, 커서 라벨
- 뺀 것과 이유 (블록 README 기준)
  - 주소 해시 연동: 페이지 라우팅은 쓰는 쪽 영역
  - 구성도 축소 맞춤: 장표 내용에 따라 다름. `detail`에 ReactNode로 넣음
  - 수치 컴포넌트: `lead.value`·`preview`에 ReactNode로 넣음

### 위험과 확인할 것
- 배너가 멈춘 커서 아래로 넘어오면 커서를 움직여야 라벨이 보인다. (웹 포트폴리오 저장소/docs/backlog.md 알려진 한계)
- 휴대폰 팝업에서 넓은 장표는 축소되어 글자가 작다. (같은 문서)
- 커서 라벨 모양(둥근/사각)은 결정 대기다. (같은 문서)
- 자동 넘김이 읽는 속도보다 빠른지 확인한다.

## 단계 분리
| 단계 | 범위                    | 확인할 것        |
|------|-------------------------|------------------|
| MVP  | 탭·배너·팝업, 자동 넘김 | 상세 열람률      |

## 유저 스토리
- 채용 담당자로서, 경력을 빠르게 파악하기 위해 그룹별 사례를 넘겨 보고 싶다.
  - Given 그룹 3개, When 두 번째 탭을 누른다, Then 그 그룹의 첫 사례가 가운데로 오고 탭 옆에 기간이 펼쳐진다.
  - Given 가운데 배너, When 왼쪽으로 배너 폭 15%(최대 80px) 넘게 끈다, Then 다음 사례로 넘어간다.
- 관심 있는 사례를 찾은 방문자로서, 근거를 확인하기 위해 상세 장표를 열고 싶다.
  - Given 가운데 배너, When 누른다, Then 장표 팝업이 열리고 페이지 스크롤이 잠긴다.
  - Given 팝업 열림, When 장표 안쪽을 누른다, Then 닫히지 않는다. 배경·닫기·Esc로만 닫힌다.
- 읽는 중인 방문자로서, 내용을 놓치지 않기 위해 자동 넘김이 멈추길 원한다.
  - Given 자동 넘김 중, When 배너에 마우스를 올린다, Then 넘김이 멈춘다.
  - Given 정지 버튼 누름, When 시간이 지난다, Then 넘어가지 않는다.

## 기능 명세
### 상태
| 상태      | 화면                   | 들어오는 조건       | 나가는 조건     |
|-----------|------------------------|---------------------|-----------------|
| 자동 넘김 | 간격마다 다음 사례     | 멈춤 조건 없음      | 멈춤 조건 생김  |
| 멈춤      | 현재 사례 유지         | 올림·접촉·포커스 등 | 조건 해제       |
| 끄는 중   | 배너가 손을 따라감     | 가로 8px 이상 끌기  | 놓음            |
| 팝업      | 장표 모달, 스크롤 잠김 | 가운데 클릭, Enter  | 닫기, 배경, Esc |

### 동작
- 배너는 한 칸에 겹쳐 두고 `transform`으로만 옮긴다. 배너 높이가 같아 넘겨도 아래가 출렁이지 않는다.
- 마지막 다음은 첫 사례로 돈다.
- 양옆 배너 간격은 24px 이하, 나머지 바깥 여백에 옆 배너가 흐리게 걸친다.
- 탭 밑줄은 탭 사이를 미끄러지고, 탭 줄이 넘치면 고른 탭이 보이게 가로 스크롤한다.
- 키보드: 사례 영역은 좌우 화살표·Enter, 탭 줄은 좌우 화살표·Home·End.
- 가운데 배너 위에서는 커서 대신 `pointerLabel`이 따라다닌다.

### 예외
- 자동 넘김 멈춤: 정지 버튼, 마우스 올림, 터치 접촉, 키보드 포커스, 끄는 중, 팝업 열림, 동작 줄이기, 화면 절반 미만 노출.
- 끌기로 끝난 누름: 클릭으로 치지 않는다.
- 동작 줄이기: 넘김 전환 애니메이션과 정지 버튼을 없앤다.
- 탭 키보드 이동에서 사례 없는 그룹: 건너뛴다.
- 사례 없는 그룹: 탭을 비활성으로 보인다. 누를 수 없고 키보드 이동도 건너뛴다.
- `pages` 빈 배열: 아무것도 그리지 않는다.

### 측정
- 출처 문서에 이벤트 정의가 없다. 이름은 모두 (가정).
- `binder_page_changed` { page_id, group_id, source: "auto" | "drag" | "click" | "key" | "tab" }
- `binder_detail_opened` { page_id }
- `binder_autoplay_paused` { reason: "button" | "hover" | "touch" | "focus" }
